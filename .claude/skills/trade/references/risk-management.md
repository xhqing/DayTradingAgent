# 风控细节（详细参考）

> 本文件是 trade skill `SKILL.md` 的风控数学与选仓位详细参考。`SKILL.md` 只保留「硬性护栏」编号 + 一行摘要；下单前算仓位、定止损位、选离散档、核对 max_loss 上限时读取本文件。

## 单笔预算 B 与 max_loss M（固定比例动态下注，两个概念先分清、不混用）

- **单笔预算（budget，B）= 开仓前由「总资产 × 固定比例 f」算出的下注预算**：B = `config.risk.risk_fraction`（当前 2%）× 当前 equity（初始 `config.risk.initial_equity` = 100000 HKD；preflight 启动时输出当前 B）。这是开仓**之前**定下的「这笔想承担多少风险」的目标值，用来当仓位选择的标尺。
- **max_loss（M）= 实际开仓之后、开仓价格到止损价格的真实最大损失**：M = 仓位 × 每股止损距（每股止损距按**实际成交价**算；开仓前用参考价预估、成交后按实际成交价精算）。这是开仓**之后**实际承担的风险额度，是真实的「这笔最多亏多少」。
- ⚠️ **max_loss 不要求严格 ≤ 单笔预算 B**（见下「选仓位」），它围绕 B 选最近、可略超或略低。

## 止损位 = 趋势反转位 = 逻辑失效点（不是限制亏损幅度、不是放远兜底防扫）

**先定止损位**：止损位 = **趋势反转判断位 = 做多/做空逻辑失效的关键位**——价格到这里 = 开仓逻辑不成立了 = 趋势大概率反转 = 该离场。

- **做多**：开仓逻辑若赖「站上 VWAP / 企稳某支撑」，止损 = **跌破该 VWAP / 企稳支撑**（站不上 VWAP = 多头逻辑失效）。
- **做空**：开仓逻辑若赖「VWAP 下方 / 遇阻某阻力」，止损 = **站上该 VWAP / 阻力**。

**止损的本质是「判断趋势反转」、不是「限制亏损幅度」、更不是「放远兜底防扫」**：让利润奔跑的前提是持仓顺势，止损只在趋势反转时触发（顺势不触发 = 利润奔跑、反转触发 = 离场不逆势扛）。这是开仓时的初始止损位（用法 B）。持仓中浮盈变大后，止损单还有「锁利」用法（用法 A，把止损移到盈利区大概率触发锁利），两种用法见 `references/trading-strategy.md`「止损单的两种用法」。

⚠️ **不要把「前低/新低下方 -X」当止损**——那是**远技术位**、不是逻辑失效点，会导致持仓逆势抗跌大亏。⚠️ **不要用百分比机械算止损**（-5% 只限幅度不判趋势）。

**反面教训（2026-07-29 07709 做多）**：开仓 35.15（逻辑 = 站上 VWAP 35.46 + 企稳），止损放新低 34.80 下方 -1.0 = 33.80（**远技术位、错**），从 35.15 跌到 33.80 逆势扛 -3.8% 大亏；**正解 = 放 VWAP 35.46 下方 35.0**（做多逻辑失效点），跌破 VWAP 即止损 -0.4% 小亏离场、不逆势扛。3x ETF 波动大 → 趋势反转位（形态支撑/VWAP）本身可能较远，**但仍按逻辑失效点定、不按百分比、不人为放远兜底**。

**算每股止损距**：|开仓价 − 止损价|（做多做空通用，加绝对值避免做空时为负）。止损价 ≥ 开仓价（做多）或 止损价 ≤ 开仓价（做空）属方向错，不开仓。

## 选仓位（核心：选实际 max_loss 最接近单笔预算 B 的仓位，不要求 max_loss ≤ B）

1. 先算连续原始仓位 = 单笔预算 B ÷ 每股止损距（按参考价）。
2. 再按 `lot_size` 离散化（港股取整手倍数、不足 1 手不开仓；美股可零股直接取整）。
3. 在离散候选里**选使实际 max_loss（= 仓位 × 每股止损距）最接近单笔预算 B 的那个仓位**——max_loss 可略超或略低于 B，只看哪个最接近、不追求严格不超。

例：B = 2000 HKD、每股止损距 3、lot_size 200 → 原始 667 股，候选 400 股（max_loss 1200）/ 600 股（1800）/ 800 股（2400），600 股的 1800 最接近 2000 → 选 600 股（max_loss 1800 < B 2000）。

⚠️ **f_max 硬上限（开仓前选仓位）**：按参考价选仓位时，选中的仓位其预估 max_loss 不得超过 `equity × config.risk.f_max`（f_max 当前 10%，是 f 的放大硬上限，preflight 输出「f_max 硬上限」）；若「最接近 B」那一档的 max_loss 已超 f_max 上限，**开仓前**退一档选更小的离散仓位。**f_max 是风控绝对红线，max_loss 可超 B 但不可超 equity × f_max**。

## 成交后超 f_max 的处理（拆两笔设两个止损单）

开仓前用参考价选仓位，但实际成交价可能偏离参考价，导致**成交后按实际成交价重算的实际 max_loss 超 f_max**。此时**禁止减仓退档**（全局禁止主动减仓），改用**拆两笔、设两个止损单**的方式把有效 max_loss 压回 f_max 以内：

- **笔 1（主体）**：止损价 = 开仓前算好的趋势反转位（**止损价不变，保证技术位置不被破坏**）。
- **笔 2（溢出部分）**：止损价更靠近成交价（即止损距更小），这部分的 max_loss 更小，用来把总 max_loss 压到 f_max 内。
- ⚠️ **两个止损单的价格不能相同**——价格相同就失去拆分意义（等于一个止损单），且可能造成重复触发混乱。

**原理**：减仓是被禁止的主动动作，但止损单触发是被动平仓（允许）。给溢出部分设一个更紧的止损，当价格反向触及它时被动减掉这部分仓位，有效锁定总损失在 f_max 内；主体部分仍守在趋势反转位的止损上，技术逻辑不变。

**计算**：设总量 Q、成交价 E、趋势反转位止损 S。若 Q×(E−S) > f_max×equity，把 Q 拆成 Q1（守 S）和 Q2（守 S2，S2 介于 E 与 S 之间、更靠近 E），使 Q1×(E−S) + Q2×(E−S2) ≤ f_max×equity。

## 美股换算

HKD 单笔预算 B ÷ 当日真实汇率（`exchange-rate` 命令查，勿估）= USD 单笔预算，再按 USD 选仓位（美股可零股、离散粒度细，max_loss 易接近 B）。

`loss_limit_scope` 默认 `per_trade`（每笔独立，无日累计上限，但 AI 自行在连亏后控制开仓频率）。

## 权益更新（从账户 API 取真实总资产，禁用占位/累加值）

**equity 必须从实际交易账户 API 取真实总资产，禁止用 config 占位值或 equity-log 手动累加值**（2026-07-31 用户立）：

- **默认账户**：用户未指定账户时，从默认账户取——港股用老虎开放平台模拟账户（`load_equity_tiger` HKD 口径 `get_prime_assets`）、美股用老虎开放平台模拟账户（`load_equity_us` 直取 USD 净值）。
- **指定账户**：用户明确指定账户时，从指定账户取。
- **`config.risk.initial_equity`（100000 HKD）仅开发期占位、不是真实资产**；`signals/equity-log.csv` 是早期信号模式手动累加值、亦非真实账户资产——两者都不得当 equity 真值用。preflight 与算仓位前一律**现查账户 API**取最新 net_assets 作 equity。
- **币种**：账户总资产如实返回（老虎美股账户 USD 计价），按账户返回币种用，换算用当日真实汇率（见上「美股换算」）。

按实际权益动态算单笔预算 B = `risk_fraction` × equity（权益缩水→B 缩、权益增长→B 放大）。

## 利润 = 赔率 R × max_loss，与标的振幅、价格贵不贵无关（纠正错误认知）

在「固定比例选仓位」的框架下，盈利 = R × max_loss（R = 净赔率，定义见 `trading-strategy.md`「赔率三阶段」），亏损 = max_loss。标的的价格只决定「买几股」（仓位股数 = max_loss ÷ 每股止损距），**不决定赚多少钱**——便宜标的多买几股、贵标的少买几股，只要 R 相同，利润一样。故**选标的不能用「振幅大→利润大」「价格低→仓位好算→利润大」作理由**，这两条都是错的。

## 做高赔率 R 有两条路，各有约束

① 放大止盈——受日内可达范围（振幅）约束，止盈位得真到得了；② 缩小止损——受「不被盘中波动扫掉」约束，太窄会被随机噪音扫成白送。两条路都能抬 R，别只盯着「放大止盈受振幅限制」而忘了「缩小止损」这条路。

## 杠杆同时影响止盈空间和止损空间——R 是增是减要看两者实际放大倍数、必须实算

R = 止盈空间 ÷ 止损空间。杠杆（3x）会把止盈空间和止损空间**同时**推大，但 R 是增是减取决于两者放大倍数孰大——分子（止盈）放大倍数 > 分母（止损）则 R 升、相等则不变、< 则降，**不能笼统说「杠杆让 R 降低」或「振幅大让 R 升高」**（同倍数放大时 R 不变）。

两者各自的实际值受不同约束：止损空间有「不被盘中波动扫掉」的下限（杠杆标的中盘中噪音大、趋势反转位在价格上天然更远，见下「杠杆 ETF 止损要远」），止盈空间受「日内可达范围」约束。**故选标的不能凭振幅或杠杆想当然，必须针对每个标的、结合实际入场位 / 止损位 / 止盈位把 R 实算出来再比较**（示例估算、非定律：按各自合理止损宽度，MU 的 R 上限约 2.3-4、SOXL 约 1.6-2.7，换止损/止盈参数结论会变）。选标的的标准是「止损能设多窄（不被扫）× 止盈能到多远」，但要落到实算 R，而非振幅绝对值或杠杆倍数。

## 仓位无比例上限

止损位近则仓位大、远则仓位小，均允许，只要实际 max_loss 不超 f_max 硬上限（软目标是 max_loss 尽量接近单笔预算 B，见上「选仓位」）。

## 止损单必须用市价触发单（STP）、禁止市价单 MKT 与限价触发单（STP_LMT）

开仓脚本（港股 `open_position_tiger.py` / 美股 `open_position_tiger_us.py`）**主单 + 附加止损腿一次提交**（持仓一旦建立就有止损保护，无裸奔空窗）；用户也会在券商 App 里手动调整止损（如改触发价移损、补挂止损单），所以最新止损单的止损价不能凭记忆，`monitor_segment.py` 每轮采样都查一次账户当日订单获取最新止损价（频率随采样间隔走）。止损位一旦定了就是纪律，不因盘中情绪滑动。

⚠️ **止损单必须用市价触发单（`STP`），禁止用市价单 `MKT`、也禁止限价触发单 `STP_LMT`**：触发价就是目标止损价，允许小范围偏差。**`MKT` 是市价单、提交即按市价成交，起不到「价格到触发价才平仓」的条件止损作用**——2026-07-31 MU 事故的真因正是误用市价单当止损（提交即市价买入平仓亏 $119，见 CHANGELOG 2026-07-31 与 `auto-mode.md`「auto 专属硬护栏」第 1 条）。`STP_LMT` 限价触发单委托价不合理时无法成交（价格跳空穿过委托价时不成交），故也禁。

## 港股每手股数是硬约束

下单量必须是整手倍数，否则报 602001。建仓前富途快照查 `lot_size`（中芯 500/手、小米 200/手、腾讯/美团/领展 100/手）。

## 港股价位 tick size

HK$0.25-100 股价最小变动 HK$0.05，挂错价位报 602035。挂限价 / 止损单前看富途盘口档位间距反推有效价位。

## 价格范围计算（修正预期赔率 ∈ [0.6, 10] 对应的入场区间；净口径）

参考价处的风险单位 R₀ = |entry_ref − stop_loss|（**毛**止损距，下单前的基准；价格范围用毛 R₀ 算、不随净口径变——80%/3/8 是经验参数），目标止盈价 T 也由参考价推算（T = entry_ref + 1.2 × R₀ 做多 / T = entry_ref − 1.2 × R₀ 做空）。**修正预期赔率为净口径**（扣双边费，见 `trading-strategy.md`「赔率三阶段」）：净 R = [|T−成交价| − r×(成交价+T)] ÷ |成交价−止损价|，r 为单边费率（港股 0.0018、美股 0.0003）。

价格范围由两部分组成（不对称，经验参数）：80% 来自风险距离的 80%，3/8 来自参考价本身。范围内**净**修正预期赔率大致在 [0.6, 10] 之间（净口径下因分子扣费、数值略低于毛口径；0.6/10 边界为经验近似、非精确对应）。

- **做多**：`[参考价 − R₀ × 0.8, 参考价 + 参考价 × 3/8]`
- **做空**：`[参考价 − 参考价 × 3/8, 参考价 + R₀ × 0.8]`
- 下界靠近止损方向（净修正预期赔率高，止损距离小，扫损概率大、胜率低；且止损越窄费率占比越高、净赔率被费侵蚀越多）。
- 上界靠近止盈方向（净修正预期赔率低，多笔交易平均实际落地赔率目标 ≈ 0.6，低于此不值得开仓）。
- 开仓脚本（`trade_utils.check_price_in_range`）自动检查当前价是否在范围内，不在则拒绝下单；输出的 `odds_at_ref` / `odds_at_current` 均为净赔率。
