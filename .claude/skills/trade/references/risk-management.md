# 风控细节（详细参考）

> 本文件是 trade skill `SKILL.md` 的风控数学与选仓位详细参考。`SKILL.md` 只保留「硬性护栏」编号 + 一行摘要；下单前算仓位、定止损位、选离散档、核对 max_loss 上限时读取本文件。

## 单笔预算 B 与 max_loss M（固定比例动态下注，两个概念先分清、不混用；max_loss 2026-08-28 起净口径）

- **单笔预算（budget，B）= 开仓前由「总资产 × 固定比例 f」算出的下注预算**：B = `config.risk.risk_fraction`（当前 2%）× 当前 equity（初始 `config.risk.initial_equity` = 100000 HKD；preflight 启动时输出当前 B）。这是开仓**之前**定下的「这笔想承担多少风险」的目标值，用来当仓位选择的标尺。
- **max_loss（M）= 实际开仓之后、这笔交易的真实最大损失（2026-08-28 起净口径，含费）**：M = 仓位 × 每股止损距 + 开仓边费 + **止损价**平仓边费（开仓前用参考价预估 = 初始预期 max_loss、成交后按实际成交价精算 = 修正 max_loss——两个变量见 `trading-strategy.md`「赔率三阶段」）。这是开仓**之后**实际承担的风险额度，是真实的「这笔最多亏多少」。**设计动机**：止损价精确成交时净亏损恰好等于 M → R 恰好 −1.000、最大亏损不深于 −1R（仅剩滑点一层）；旧「毛值 M = 仓位×止损距」口径下止损单净 R 会到 −1.2~-1.8（费占止损额 20%~80%）。两阶段（初始预期/修正）定义与公式见 `trading-strategy.md`「赔率三阶段·两个 max_loss 变量」。
- ⚠️ **max_loss 不要求严格 ≤ 单笔预算 B**（见下「选仓位」），它围绕 B 选最近、可略超或略低（净口径后 B 目标本身含义 = 净风险额，选档算法自动按净 max_loss 选最近）。

## 止损位 = 趋势反转位 = 逻辑失效点（不是限制亏损幅度、不是放远兜底防扫）

**先定止损位**：止损位 = **趋势反转判断位 = 做多/做空逻辑失效的关键位**——价格到这里 = 开仓逻辑不成立了 = 趋势大概率反转 = 该离场。

- **做多**：开仓逻辑若赖「站上 VWAP / 企稳某支撑」，止损 = **跌破该 VWAP / 企稳支撑**（站不上 VWAP = 多头逻辑失效）。
- **做空**：开仓逻辑若赖「VWAP 下方 / 遇阻某阻力」，止损 = **站上该 VWAP / 阻力**。

**止损的本质是「判断趋势反转」、不是「限制亏损幅度」、更不是「放远兜底防扫」**：让利润奔跑的前提是持仓顺势，止损只在趋势反转时触发（顺势不触发 = 利润奔跑、反转触发 = 离场不逆势扛）。**开仓初始止损与持仓移动止损同一原则：止损永远放最新趋势反转位、随结构动态改变**——做多随涨上移、做空随跌下移；**水平震荡时反转位 = 震荡区间的上沿（做空）/ 下沿（做多），区间确认后止损移到对应边界外侧，突破边界 = 逻辑失效 = 止损触发，不得把止损留在开仓远位等突破区间后才被大幅扫损**（2026-08-12 03308 教训，见 `trading-strategy.md`「移动止损」节）。（2026-08-07 用户立：无「浮盈 ≥ 2R 紧锁利」的第二种用法；锁利多少由现价到最新结构位的距离决定，停止盯盘 / 动能衰竭 / 情况不妙时主动平仓兜底）。详见 `references/trading-strategy.md`「移动止损」节。

⚠️ **不要把「前低/新低下方 -X」当止损**——那是**远技术位**、不是逻辑失效点，会导致持仓逆势抗跌大亏。⚠️ **不要用百分比机械算止损**（-5% 只限幅度不判趋势）。

**反面教训（2026-07-29 07709 做多）**：开仓 35.15（逻辑 = 站上 VWAP 35.46 + 企稳），止损放新低 34.80 下方 -1.0 = 33.80（**远技术位、错**），从 35.15 跌到 33.80 逆势扛 -3.8% 大亏；**正解 = 放 VWAP 35.46 下方 35.0**（做多逻辑失效点），跌破 VWAP 即止损 -0.4% 小亏离场、不逆势扛。3x ETF 波动大 → 趋势反转位（形态支撑/VWAP）本身可能较远，**但仍按逻辑失效点定、不按百分比、不人为放远兜底**。

**算每股止损距**：|开仓价 − 止损价|（做多做空通用，加绝对值避免做空时为负）。止损价 ≥ 开仓价（做多）或 止损价 ≤ 开仓价（做空）属方向错，不开仓。

## 止损距宽窄的核心理念：窄止损宽止盈，预期赔率的实现概率才高（2026-08-28 用户立）

**同样一个「净赔率 ≥ 1.2」的数字，窄止损宽止盈结构实现的概率远高于宽止损结构**——赔率是个比值，门槛只看比值、看不出「分子要走多远、分母会亏多深」，但落地概率完全不同：

- **窄止损宽止盈（止损距小、止盈距大）**：止损贴近逻辑失效点 → 走到止损只需很小的反向波动（判断错了很快被请出局，损失小）；止盈距虽宽，但只要趋势走对方向、利润奔跑的空间大。**判断对时吃满宽分子、判断错时只亏窄分母**——预期赔率的兑现概率高。
- **宽止损（止损距被拉大）**：止损远离入场价 → 判断错了要亏很深才触发（分母先吃满）；同时同样止盈价下比值被压低、常被迫把止盈推更远去凑门槛，分子更难到达。**两头都难**：亏的时候亏得多、赚的时候更难赚满——预期赔率「账面上」过门槛，「实现概率」很低。

**数学直觉**：预期赔率 R = 止盈距 ÷ 止损距。止损距扩到 2 倍 → 要维持同 R，止盈距也得扩到 2 倍——但价格当日可走的空间有限（当日高低点、量能、剩余时间约束，见 `trading-strategy.md`「目标止盈位必须大概率可达」），**分母可以随便拉大、分子拉不大**，于是实际只能「止损放宽 + 止盈不变」→ R 被稀释；或「止损放宽 + 止盈推远凑 R」→ 止盈变成够不到的幻想价（2026-08-21 MINIMAX 360 教训同构）。**止损距的每一次放大，都是在透支止盈的可达性。**

**实操含义**：

1. **止损距能窄则窄，宽出来是被动的、不是选择**：止损位永远放逻辑失效点（上文），逻辑失效点天然近（VWAP 下沿 / 企稳区下沿 / 颈线），止损距就该是小数字。**止损距偏大时先问「逻辑失效点真有这么远吗」**——多数情况是放远了（远技术位 / 兜底心理 / 防插针缓冲叠过头），不是结构真需要。
2. **止损距被闸门逼着放宽时，警惕赔率被稀释**：印花税闸要求止损距 ≥ 0.4%×股价（个股），有时为过闸把止损从结构位放宽——放宽后必须重看净赔率（脚本会按新止损距重算 `odds_at_current`），**放宽后的 R 比原结构 R 低才是真实 R**，不要拿放宽前的赔率做心理锚。
3. **入场点本身就是止损距的第一决定因素**：离逻辑失效点越近入场（回踩企稳位附近买、突破回踩确认位附近买），止损距天然越小——「入场点质量」的本质之一就是「止损距质量」。追高入场（离失效点远）天然止损距大，是位置差的直接代价。

**反面教训（2026-08-28 09988 第二笔）**：突破回踩追入 @114.2，结构止损本应放回踩区下沿 113.95 附近（止损距 ~0.25）。首挂 113.55 被印花税闸拦（税闸按**下单时现价**判定：做多要求 |现价 − 止损| ≥ 0.4%×现价，现价 114.0 → 止损须 ≤ 113.54；113.55 距 0.45 = 0.395%，差 0.006 未过）。改挂 113.5 过闸但限价未成交撤单；11:22 现价已 114.1，**直接沿用 113.5 没重算贴线**（此时税闸线已上移到 113.64），成交 @114.2。实现止损距 0.7 的分解：**0.25 结构位 + ~0.31 税闸强制 + ~0.14 沿用旧值未贴线（113.64→113.5）+ 0.10 入场滑点（ask 跳价、成交高于下单现价）**——税闸是大头但非全部，贴线挂 113.64 的净赔率 ≈1.72 vs 实际 1.38（复核实算，初记 1.35 已按 CHANGELOG 2026-08-28 归因修正段更新），多让的 ~0.14 白丢了近 0.4R 账面赔率。结果方向判断完全正确（价格走到 114.7），但宽止损 + 费用 388 吃掉 88% 毛利、落地仅 +0.07R——**方向对了却几乎不赚钱**。三条正解：① 被闸门放宽时只放宽到闸门线的最小值（**贴线过闸、每 0.01 都是赔率**），且现价变动后重算税闸线、不沿用旧止损价；② 结构位止损（113.95，距 0.25）过不了 0.4% 税闸，说明**该入场点的止损距与个股税闸天然不兼容——换入场点（等更深回踩拉大结构距离）或换 ETF，而不是放宽**；③ 注意税闸方向：做多**止损放得更低**才过闸，「往回收一点」的方向永远是更过不了闸的方向。

## 止损位防插针缓冲（2026-08-25 立，07747 插针教训）

**规则**：止损位定在趋势反转位的基础上，**离开显眼结构位与整数关口一点缓冲**，避免被「打掉拥挤止损区的插针」扫损——止损单是券商侧毫秒级条件单，AI 侧采样再密都拦不住插针，只能在**放的位置**上做文章：

1. **缓冲距离 = 结构位外侧 0.25 × 5 分钟 ATR**（做多放支撑位下方、做空放阻力位上方——注意方向：缓冲是让止损价**离开**结构位更远，不是贴着结构位挂）。例：颈线支撑 72.2、5 分钟 ATR 0.4 → 做多止损放 72.1（72.2 − 0.25×0.4）而非 72.2 正位。**为什么 0.25×ATR**：太小挡不住针、太大遇到真破位多亏缓冲距离；0.25 倍是初始经验值，待复盘用「止损触发后 N 分钟内收回结构位」的插针回收率统计再标定（见下第 4 条）。
2. **避开整数关口**：72.0 / 72.2 / 330 / 100 这类整数位与半整数位是全市场止损单的拥挤区、针最爱的落点，止损价能放 72.15 就不放 72.2、能放 329.8 就不放 330。
3. **代价要心里有数（这是保险费、不是免费的）**：止损距变大 → 同预算下仓位变小、同止盈下净赔率变低、真破位时多亏缓冲距离。**方向只能是「挪位置」、绝不能是「松纪律」**——为躲偶尔的插针放宽止损或撤止损，一次真破位亏的钱比十次插针还多（2026-08-12 03308「死守开仓远位被放量突破扫损 −1.28R」反面教训）。止损单该触发就触发，纪律无瑕疵的止损亏损（如 2026-08-25 07747 −1.79R）是制度成本、不是错误。
4. **复盘可验证的量化题（复盘时做、不在盘中做）**：统计历史样本「止损触发后 N 分钟内收回结构位」的比例（插针回收率）。回收率显著高 → 缓冲系数可再放大；不显著 → 缓冲建议只是安慰剂、按样本说话调整或撤销本条。

**2026-08-25 07747 实录（立条依据）**：做多 1900 股 @72.34，止损挂双底颈线 72.2 **正位**（既是结构位又是整数关口，双重拥挤），13:59 插针 72.08 打掉止损成交 72.17、随即 V 型收回 72.3+ 并续走 72.5-72.8——若按本条缓冲放 72.1，该针打不到。事后看这笔 −476 HKD / −1.79R 纪律正确，但位置可优化。

## 选仓位（核心：选实际 max_loss 最接近单笔预算 B 的仓位，不要求 max_loss ≤ B；max_loss 2026-08-28 起净口径）

1. 先算连续原始仓位 = 单笔预算 B ÷ 每股止损距（按参考价）。
2. 再按 `lot_size` 离散化（港股取整手倍数、不足 1 手不开仓；美股可零股直接取整）。
3. 在离散候选里**选使实际 max_loss（2026-08-28 起净口径 = 仓位 × 每股止损距 + 开仓边费 + 止损价平仓边费；`trade_utils_tiger.calc_position_size` 传齐 sec_type/market/stop_price/entry_price 即净口径）最接近单笔预算 B 的那个仓位**——max_loss 可略超或略低于 B，只看哪个最接近、不追求严格不超。

例：B = 2000 HKD、每股止损距 3、lot_size 200、参考价 100、港股个股 → 原始 667 股；毛口径候选 400 股（1200）/ 600 股（1800）/ 800 股（2400）；净口径下 600 股净 max_loss = 1800 + 开仓费 + 止损费 ≈ 1998（费随股数加进各档），600 股仍最接近 2000 → 选 600 股（实跑验证：净口径选档与毛口径同为 600 股）。

⚠️ **f_max 硬上限（开仓前选仓位）**：按参考价选仓位时，选中的仓位其预估**净** max_loss 不得超过 `equity × config.risk.f_max`（f_max 当前 10%，是 f 的放大硬上限，preflight 输出「f_max 硬上限」）；若「最接近 B」那一档的 max_loss 已超 f_max 上限，**开仓前**退一档选更小的离散仓位。**f_max 是风控绝对红线，max_loss 可超 B 但不可超 equity × f_max**（净口径后费也计入 cap 比较，脚本已逐档净精算判 cap）。

⚠️ **开仓市值杠杆上限（2026-08-08 立）**：开仓市值 = 仓位 × 开仓价（参考价估算），**不得超过 `equity × config.risk.max_leverage`**（max_leverage 默认 10，即 10 倍杠杆——权益 10 万最高开 100 万市值）。**与 f_max 是两套独立约束**：f_max 限 max_loss（风险敞口）、max_leverage 限开仓市值（名义敞口），选仓位时**两者同时满足**——离散候选档里先剔除「max_loss > equity×f_max」或「市值 > equity×max_leverage」的档，再在剩余档里选最接近 B 的。若最接近 B 的那档超市值上限、退一档仍超，则继续退档直至 ≤ 上限；所有档都超（止损距过小导致原始仓位过大）则不开仓（仓位返回 0）。`trade_utils_tiger.calc_position_size` 已实现该约束（max_leverage=None 时自动读 config.risk.max_leverage）。

## 成交后超 f_max 的处理（拆两笔设两个止损单）

开仓前用参考价选仓位，但实际成交价可能偏离参考价，导致**成交后按实际成交价重算的实际（净）max_loss 超 f_max**。此时**禁止减仓退档**（全局禁止主动减仓），改用**拆两笔、设两个止损单**的方式把有效 max_loss 压回 f_max 以内：

- **笔 1（主体）**：止损价 = 开仓前算好的趋势反转位（**止损价不变，保证技术位置不被破坏**）。
- **笔 2（溢出部分）**：止损价更靠近成交价（即止损距更小），这部分的 max_loss 更小，用来把总 max_loss 压到 f_max 内。
- ⚠️ **两个止损单的价格不能相同**——价格相同就失去拆分意义（等于一个止损单），且可能造成重复触发混乱。

**原理**：减仓是被禁止的主动动作，但止损单触发是被动平仓（允许）。给溢出部分设一个更紧的止损，当价格反向触及它时被动减掉这部分仓位，有效锁定总损失在 f_max 内；主体部分仍守在趋势反转位的止损上，技术逻辑不变。

**计算**（2026-08-28 起净口径，含各笔开仓费与止损边费）：设总量 Q、成交价 E、趋势反转位止损 S。若 Q×(E−S) + 开仓费(E,Q) + 止损费(S,Q) > f_max×equity，把 Q 拆成 Q1（守 S）和 Q2（守 S2，S2 介于 E 与 S 之间、更靠近 E），使 Q1×(E−S) + Q2×(E−S2) + 开仓费(E,Q) + 各笔止损费 ≤ f_max×equity（拆笔费按各自股数与价格算）。

## 利润 = 赔率 R × max_loss，与标的振幅、价格贵不贵无关（纠正错误认知）

在「固定比例选仓位」的框架下，盈利 = R × max_loss（R = 净赔率、max_loss 净口径含费，定义见 `trading-strategy.md`「赔率三阶段」），亏损 = max_loss（止损价精确成交时 R = −1、亏满 max_loss；无滑点时不深于 −1R）。标的的价格只决定「买几股」（仓位股数按毛止损距近似再离散选档），**不决定赚多少钱**——便宜标的多买几股、贵标的少买几股，只要 R 相同，利润一样。故**选标的不能用「振幅大→利润大」「价格低→仓位好算→利润大」作理由**，这两条都是错的。

## 做高赔率 R 有两条路，各有约束

① 放大止盈——受日内可达范围（振幅）约束，止盈位得真到得了；② 缩小止损——受「不被盘中波动扫掉」约束，太窄会被随机噪音扫成白送。两条路都能抬 R，别只盯着「放大止盈受振幅限制」而忘了「缩小止损」这条路。

## 杠杆同时影响止盈空间和止损空间——R 是增是减要看两者实际放大倍数、必须实算

R = 止盈空间 ÷ 止损空间。杠杆（3x）会把止盈空间和止损空间**同时**推大，但 R 是增是减取决于两者放大倍数孰大——分子（止盈）放大倍数 > 分母（止损）则 R 升、相等则不变、< 则降，**不能笼统说「杠杆让 R 降低」或「振幅大让 R 升高」**（同倍数放大时 R 不变）。

两者各自的实际值受不同约束：止损空间有「不被盘中波动扫掉」的下限（杠杆标的中盘中噪音大、趋势反转位在价格上天然更远，见下「杠杆 ETF 止损要远」），止盈空间受「日内可达范围」约束。**故选标的不能凭振幅或杠杆想当然，必须针对每个标的、结合实际入场位 / 止损位 / 止盈位把 R 实算出来再比较**（示例估算、非定律：按各自合理止损宽度，MU 的 R 上限约 2.3-4、SOXL 约 1.6-2.7，换止损/止盈参数结论会变）。选标的的标准是「止损能设多窄（不被扫）× 止盈能到多远」，但要落到实算 R，而非振幅绝对值或杠杆倍数。

## 仓位无比例上限

止损位近则仓位大、远则仓位小，均允许，只要实际 max_loss 不超 f_max 硬上限（软目标是 max_loss 尽量接近单笔预算 B，见上「选仓位」）。

## 止损单必须用市价触发单（STP）、禁止市价单 MKT 与限价触发单（STP_LMT）

开仓脚本（港股 `open_position_tiger.py` / 美股 `open_position_tiger_us.py`）**主单 + 附加止损腿一次提交**（持仓一旦建立就有止损保护，无裸奔空窗）；用户也会在券商 App 里手动调整止损（如改触发价移损、补挂止损单），所以最新止损单的止损价不能凭记忆，`monitor_segment.py` 每轮采样都查一次账户当日订单获取最新止损价（频率随采样间隔走）。止损位一旦定了就是纪律，不因盘中情绪滑动。

⚠️ **止损单必须用市价触发单（`STP`），禁止用市价单 `MKT`、也禁止限价触发单 `STP_LMT`**：触发价就是目标止损价，允许小范围偏差。**`MKT` 是市价单、提交即按市价成交，起不到「价格到触发价才平仓」的条件止损作用**——2026-07-31 MU 事故的真因正是误用市价单当止损（提交即市价买入平仓亏 $119，见 CHANGELOG 2026-07-31 与 `auto-mode.md`「auto 专属硬护栏」第 1 条）。`STP_LMT` 限价触发单委托价不合理时无法成交（价格跳空穿过委托价时不成交），故也禁。

## 费率与成本（2026-08-12 立，老虎真实费率取代旧 18bps 笼统口径；2026-08-17 平台费改固定模式 + 美股改按股结构）

**单边费** = 一次成交的费用（开仓算 1 边、平仓算 1 边，各自按各自成交额/股数计费）。每笔交易成本 = 开仓边费 + 平仓边费。统一费率逻辑在 `scripts/fee_schedule.py`（复盘 + 前瞻共用，改费率只改该文件）。**港美两市场计费结构不同**：

```
港股（按额 + 按笔，计价 HKD）：
  单边费 = 佣金 + 印花税(个股) + 交易费 + 结算交收费 + 交易征费 + 财汇局征费 + 平台费
    佣金        = max(15, 成交额 × 0.029%)          老虎佣金，最低 15 港元/笔
    印花税      = 成交额 × 0.1%                       港股个股收（买卖各 0.1%）；港股 ETF/窝轮/CBBC 免

美股（按股，计价 USD）：
  单边费 = 佣金 + 平台费 + 代收费近似
```

1. **期望落地基准**（2026-08-24 版原话，已被 2026-08-25 下调实证修正，见第 5 步）：开仓门槛是初始净赔率 ≥ 1.8R（净口径、已扣费；原 2.4R；2026-08-25 现行 1.2R，读 config.risk.min_net_odds）。历史样本（`trading-strategy.md`「预估赔率系统性打折」，执行门槛后样本）标定**落地/初始兑现率 ≈ 25%**——1.8R 仓位期望落地 ≈ **0.45R**（原 2.4×25% = 0.6R）。这 0.45R 是一笔交易的全部期望产出，所有成本摩擦都从这里面出。
2. **印花税 R 损耗公式**：双边印花税 = 0.1%×2×成交额 ≈ 0.2%×入场价×股数；max_loss = 股数×止损距。相除得 **印花税 R 损耗 = 0.2%×入场价 ÷ 止损距**——股数约掉后**只与「止损距占股价的百分比」有关、与仓位大小无关**。这就是为什么小账户小仓位与模拟盘大仓位遭遇的是同一个比例问题，只是大仓位毛利基数大、感知不到。
3. **阈值 = 期望落地的 20%**：0.09R ÷ 0.45R = 20%（原 0.12R ÷ 0.6R = 20%，占比不变）。取 20% 的理由：① 参照系——**佣金 R 损耗 = 0.058%×股价 ÷ 止损距**（双边 0.029%×2，最低 15/边未触发时），在闸值 2.22% 止损距下为 0.026R（占期望落地 6%）、止损距 1% 时 0.058R（约 13%）；**平台费 R 损耗 = 30 ÷ max_loss**（双边固定 30 HKD），依赖股数×止损距的绝对值而非比例。印花税作为单一税项给到 20% 已是佣金与平台费之外的最大成本项，再高则交易动机从「赚形态的钱」劣化为「给税局打工」；② 全场景恶化性——印花税在**止损单上同样照缴**（平仓也收 0.1%），它不像滑点那样只在不利场景出现，而是拉低包括止损在内的所有分支的期望；③ 若允许 0.4R（2026-08-18 腾讯实际值），毛赔率须 ≥2.6R 才凑出净 1.8R（原 2.4R 门槛下须 ≥3.0R）、目标价须在近 3 倍止损距外——日内窄止损结构下极少给得起，等于变相禁开，不如把闸值明示。
4. **换算成止损距**（2026-08-24 版）：0.2%×股价 ÷ 止损距 ≤ 0.09R → 止损距 ≥ 0.002/0.09 = **2.22%×股价**（原 0.002/0.12 = 1.67%）。
5. **2026-08-25 用户下调 2.22% → 1.2%**（实证推翻第 1 步的 25% 兑现率标定）：48 笔样本实测——① 真实兑现率 0.62R（个股 0.66R），旧标定 25% 低估近 3 倍，按真值与 1.2R 门槛联动公式（0.002 ÷ (1.2×0.62×20%)）应为 1.34%，取 1.2% 略激进；② 40 笔个股中 34 笔（85%）止损距不足 2.22%、会被旧闸拦掉，这 34 笔**已扣税**真实落地合计 +24.3R（22 笔盈利）——错杀大于保护；③ 这 34 笔实际税损 ÷ 实际净利 ≈ 17%-20%，恰在原设计上限内，税并未吃掉交易动机。代价口径：1.2% 闸下压线单笔税损上限 0.167R。常见标的具体值（0.4% 口径）：腾讯 440 → ≥1.8 元；阿里 113 → ≥0.45 元；中芯 66 → ≥0.26 元；小米 28 → ≥0.11 元。
5. **标定事故**：2026-08-18 腾讯两笔（止损距 2.2/2.0 元 = 0.50%/0.45% 股价，按当时口径印花税 R 损耗 0.40R/0.44R、占当时期望落地 67%/73%）——毛口径两笔合计 +300 HKD、方向都对，净口径 −512.5 HKD，印花税 532 HKD 是最大成本项。若当时换 ETF（免印花税）净口径约 +172——闸值就是从这笔事故反推的。

**工具落地**（按「文档规定配工具强制」）：① `open_position_tiger.py` 下单硬校验（2026-08-25 立）——按**实际入场价**口径，个股止损距 < `config.risk.stamp_tax_gate_pct`×入场价即拒单（`blocked_by:"stamp_tax_gate"`），先于止盈可达性 / 净赔率校验执行；② `hot_list.py` 榜单带「类型」列 + 「个股税闸止损≥」列（读 config 同值）——选品第一步就能看到每只个股的合规最小止损距；③ `pool_claim.py` 认领预检（读 config 同值）——认领时点即警告「过闸概率低」；④ 开仓前自查清单硬性条目（SKILL.md「开仓前自查清单」）——个股未过闸不得开、动作记录须注明「印花税闸已过」。2026-08-25 前「无法工具硬拦」的理由（止损位由 AI 现场判定、脚本层无法预知）已被突破：校验点放在**下单时刻**（止损价已是确定的命令行参数），AI 定完止损价传给脚本、脚本按实际入场价机械验闸——AI 判定归 AI、机械验闸归脚本。

## 价格范围计算（修正预期赔率 ∈ [0.6, 10] 对应的入场区间；净口径）

参考价处的风险单位 R₀ = |entry_ref − stop_loss|（**毛**止损距，下单前的基准；价格范围用毛 R₀ 算、不随净口径变——80%/3/8 是经验参数），目标止盈价 T 也由参考价推算（T = entry_ref + 1.2 × R₀ 做多 / T = entry_ref − 1.2 × R₀ 做空）。**修正预期赔率为净口径**（扣双边费 + 2026-08-28 起分母也含费，见上方「费率与成本」+ `trading-strategy.md`「赔率三阶段」）：净 R = [|T−成交价|×N − fee开仓(成交价) − fee止盈(T)] ÷ [止损距×N + fee开仓(成交价) + fee止损(S)]，两边费按各自价格分开算、N=股数，费按老虎真实费率算（港股按额+固定平台费 15/笔、美股按股）。

价格范围由两部分组成（不对称，经验参数）：80% 来自风险距离的 80%，3/8 来自参考价本身。范围内**净**修正预期赔率大致在 [0.6, 10] 之间（净口径下分子扣费 + 分母加费、数值明显低于毛口径，窄止损单压得更多；0.6/10 边界为经验近似、非精确对应——参数沿旧口径标定，未随 2026-08-28 净分母改版重标，如后续发现边界失准再调）。

- **做多**：`[参考价 − R₀ × 0.8, 参考价 + 参考价 × 3/8]`
- **做空**：`[参考价 − 参考价 × 3/8, 参考价 + R₀ × 0.8]`
- 下界靠近止损方向（净修正预期赔率高，止损距离小，扫损概率大、胜率低；且止损越窄费率占比越高、净赔率被费侵蚀越多）。
- 上界靠近止盈方向（净修正预期赔率低，多笔交易平均实际落地赔率目标 ≈ 0.6，低于此不值得开仓）。
- 开仓脚本（`trade_utils.check_price_in_range`）自动检查当前价是否在范围内，不在则拒绝下单；输出的 `odds_at_ref` / `odds_at_current` 均为净赔率（2026-08-28 起净分母口径；quantity=0 自动算仓位前的检查因股数未知退旧百分比估分子、毛分母，算出仓位后按真实费率复核）。
