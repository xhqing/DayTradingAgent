# 交易策略与教训（详细参考）

> 本文件是 trade skill `SKILL.md` 的交易策略、入场形态、移动止损、市场结构判据与历史教训详细参考。`SKILL.md` 只保留策略核心骨架；具体判据、形态定义、反面教训全部在本文件。开仓前判方向 / 选入场点、持仓中决定移损 / 平仓时读取。

## 核心思想：数学期望 EV ≥ 0（最高优先级）

一切交易决策围绕 **EV ≥ 0**（至少不亏），EV > 0 且越大才挣得多。EV 由多笔交易的**胜率 × 赔率**决定——这是能否盈利的地基，方向/风控/纪律都服务于它。

## 开仓基准

开仓必须同时满足 **胜率 > 50% 且 初始预期赔率 ≥ 1.2**（**净赔率**，扣双边手续费：港股 18bps/边、美股 3bps/边，见下「赔率三阶段」）。EV = 胜率×初始预期赔率 − 败率×1。⚠️ **「初始预期赔率 ≥ 1.2」是打 ×0.5 经验折扣后的口径**——开仓判 EV 时先把算出的初始预期赔率乘 0.5 再与 1.2 门槛比（等价于初始预期赔率 ≥ 2.4 才开仓）。原因与标定数据见下「预估赔率系统性打折」节。

⚠️ **初始预期赔率 ≥ 1.2 与「止损给足波动空间」不矛盾**：止损仍按 K 线形态技术位定（前低/支撑，**禁止百分比**），3x 杠杆 ETF 波动大 → 选更远的形态支撑位防噪音扫。移动止损仍用于浮盈后锁利与进一步放大利润，但**开仓那一刻初始预期赔率本身就要 ≥ 1.2，不能指望靠移动止损把一个低赔率的仓补成正期望**。

## 预估赔率系统性打折（2026-08-05 三阶段样本标定）

初始预期赔率是「形态完美延续到止盈」的理想值，实际落地会被两层折扣侵蚀：① 滑点 + 止损距重算（初始 → 修正）；② 平仓时机 / 形态失效（修正 → 落地）。复盘三阶段赔率反复暴露「预估乐观、落地打折」——**按 1.2 门槛放行的大批仓位实际落地为负，门槛形同虚设**。

**标定数据（2026-08-03~08-05 全部可配对三阶段记录，12 笔初始 ≥ 1.2 样本）**：
- 落地/初始 比值：中位数 −0.22、均值 −0.08——平均落地 ≈ 打平（初始均值 2.69R、落地均值 −0.11R）；
- **75%（9/12）落地 ≤ 0**，仅 3 笔落地 > 0（01888 两笔达标锁利 + NVDA +1.06R），深亏笔（约 −1.4R）来自突破 / 反抽假信号快速失效；
- 敏感性：按 ×0.6 卡（初始 ≥ 2.0）→ 会开 8 笔、胜 3、落地合计 +0.98R；×0.5（≥ 2.4）→ 6 笔、胜 2、+0.84R；×0.4（≥ 3.0）→ 3 笔、胜 1、+1.35R——**门槛提高只能「少开」、不能保证「多赢」**（打折分布宽、正负都有），打折是收紧出手的保守化处理、不是赢钱机器。

**规则**：开仓判 EV 时，初始预期赔率先打 **×0.5 经验折扣**再与 1.2 门槛比（即初始预期赔率 ≥ 2.4 才开仓）。修正预期赔率（成交后）照常记录，但不作为开仓判据（已成交、只影响仓位复核）。

**边界（严谨性，勿过度外推）**：
1. **×0.5 是保守粗标定、不是精确最优**：样本仅 12 笔、中位兑现率远低于 ×0.5，取 ×0.5 是怕把边缘单全误杀的保守值；待三阶段记录积累（≥ 30 笔）后按「落地/初始」分布重新标定系数；
2. **打折是收紧出手、不是保证赢**：×0.5 卡门槛下 6 笔仍 4 笔亏——落地差的根子在「形态质量 + 让利润奔跑」（深亏多来自假突破 / 反抽假信号，达标锁利则兑现好），提高赔率门槛治标不治本，形态确认与止盈纪律照常是重点；
3. **与「目标止盈必须大概率可达」互补**：止盈不可达是打折的主要来源之一（2026-08-03 立），开仓前止盈目标仍须按当日大概率可达检验，打折不替代它；
4. 打折只作用于「初始预期赔率 vs 1.2 门槛」的比较环节，不动止损位、止盈位的定法（仍按形态技术位），不改 max_loss / 仓位计算。

## 置信度分级——EV 之上的第二道闸

EV 判据是「这笔值不值得做」的数学门槛；置信度是「我对这个判断有多大把握」的可靠度分级。**开仓只在 🟢 高置信时执行，🟡 中置信 / 🔴 低置信都不开仓**（真实交易，置信度把质量关）。判级标准：

- **🟢 高置信（唯一可开仓的级别）**：各维度一致（趋势 + 量价 + 资金流 + 宏观基调同向）、入场点建立在已确认事实（企稳 / 真站稳）、（若有临近重大事件）事件经「事件风险三维度判别」评估不构成对该标的方向的主导性冲击 → 执行开仓。
- **🟡 中置信（不开仓）**：部分维度矛盾或待确认（趋势顺势但量价未配合、资金流与盘口背离、临近数据日但方向不明、已标注反向风险）→ **不开仓**，等确认升到高置信再开（反面案例：SOXL 做空定中置信、已标注超大单逆势买风险仍发、致用户实亏 ~$120）。
- **🔴 低置信（不开仓）**：关键维度矛盾、横盘无明确方向、临近重大事件（CPI / 非农 / FOMC / 财报）**且该事件对标的方向主导性强、结果落地前方向难判**（不是机械「有事件就降级」，见下「事件风险三维度判别」）、依据是赌突破 / 赌反转（预测非已确认）→ **不开仓**，等局面明朗。其中「关键维度矛盾」指**对入场方向不利的量价背离 / 资金流反向**（如做多时缩量上涨、做空时缩量下跌、做多时资金流出、做空时资金流入）——注意量价背离本身不是低置信信号，要看它是否对你要做的方向不利：做空时放量下跌也是量价背离，但对做空是确认信号、属高置信。
- 置信度写入开仓动作「置信度」字段（圆形彩色 emoji 🟢/🟡/🔴 标记，是表格内唯一可保留的 emoji）。⚠️ **置信度是硬闸**（仅 🟢 开仓，🟡/🔴 都不开仓）。置信度不取代硬护栏（标的分类、时段、max_loss 等仍硬性），但开仓门槛是「🟢 高置信 + 赔率 ≥1.2」两道闸全过才开仓。

## 事件风险三维度判别

临近重大事件（CPI / 非农 / FOMC / 财报 / 地缘 / 政策等）时，事件对置信度的影响权重**不能机械「有事件就降级」**，要具体分析三个维度：

- **① 方向**：事件预期结果对标的的方向（利好 / 利空 / 中性）。与持仓方向**相反** → 风险高；**一致**或**中性** → 风险低。
- **② 程度**：事件结果的市场预期已 price in 多少。预期一致 + 概率高（如 FOMC 79.5% 维持不变）= 大概率已 price in = 实际冲击**小**；预期分歧 / 结果难测 = 冲击**大**。
- **③ 是否影响主导驱动（最关键）**：先识别标的**当下最主要的价格主导原因**（独立基本面 / 行业周期 / 技术形态 / 资金流 / 还是事件预期本身），再判断事件会不会**改变**这个主导驱动——事件**是**主导驱动本身（如大盘 ETF、无独立逻辑的标的在事件前）→ 事件权重高、结果落地前**降级**；标的有**独立主导驱动**（如板块独立崩、有自身基本面逻辑）且事件**不改变**它 → 事件权重**低**、技术信号效力不被削弱、**不降级**。

**判别口诀**：机械「有事件就降级」是错的。要问——**事件会改变这个标的当下的主导驱动吗？会 → 谨慎；不会 → 即便有事件、技术信号效力不打折**。

**反面教训（2026-07-27 MU）**：21:53 MU VWAP 927 假突破遇阻、半导体独立崩跌（大盘涨它崩 = 有独立空头驱动），做空判断本应 🟢，但误把「明天 FOMC」机械当降级因素判 🟡 不开仓。实际：FOMC 79.5% 预期不变（② 程度小）+ 半导体独立崩跌（③ FOMC 不改变独立空头驱动）→ 事件权重低、不该降级。错过入场 925–937 止损的做空点（收盘 899，浮盈 26–38 点）。**根因：没区分「事件主导型标的」和「独立驱动型标的」，把 🟢 高置信里「无临近重大事件」机械执行。**

## 赔率三阶段（贯穿开仓→持仓→平仓，三阶段统一净口径）

赔率在交易生命周期有三个时点，各自用不同基准价算、名称不同。**三阶段一律净口径——扣双边手续费（港股 18bps/边、美股 3bps/边，开仓 + 平仓两边各收一次单边费率）**，与复盘 `review.py` 的 $R = 净盈亏 ÷ 毛 max_loss 同口径（2026-08-04 用户立：盯盘前瞻赔率从毛口径改为净口径、与复盘统一；基点单边，港股 18bps/边、美股 3bps/边）。**分子扣双边费、分母（止损距 / max_loss）保持毛值不动**——止损距是开仓前定下的风险预算标尺、归一化基准，不被费率改动。设单边费率 $r$（港股 $0.0018$、美股 $0.0003$）、入场价 $E$、止盈 $T$、止损 $S$：

1. **初始预期赔率**（开仓前，$E=$ 参考价，净）$= \big[|T-E| - r(E+T)\big] \div |E-S|$。分子 = 到止盈的净盈利（止盈距扣双边费，平仓按止盈价 $T$ 算费）；分母 = 毛止损距。即开仓动作「初始预期赔率」字段；**$\geq 1.2$ 才开仓**。开仓前必须先定止盈线 + 止损线才能算出、再判开仓。
2. **修正预期赔率**（实际开仓后，$E=$ 实际成交价，净）$= \big[|T-E| - r(E+T)\big] \div |E-S|$，$E$ 换成实际成交价。反映真实成本下的赔率预期，**成交后立即算**，写入动作文件。
3. **实际落地赔率**（平仓后，净）$= 净盈亏 \div 实际 max\_loss$（$= R$-multiple，$R_i=P_i^{net}/M$；$M = 仓位 \times |开仓成交价 - 止损价|$ 为毛值；净盈亏 $= 毛盈亏 - r\times(开仓成交价 + 平仓成交价)\times 仓位$，平仓按实际平仓价算费）。开仓/平仓成交价都是脚本返回的真实成交价。已了结的真实赔率，**停盯总结必报**。

**为什么分子扣费、分母不扣**：赔率衡量「冒 1 单位风险换多少回报」——分子是回报（扣掉成本才是真到手）、分母是风险预算标尺（毛值固定、作归一化基准），故只扣分子。若分母也扣费，止损时净亏损 $> M$、$R$ 跌破 $-1$，与「冒 $M$ 风险」的语义混乱；保持分母毛值，止损时 $R$ 略低于 $-1$（多亏一笔平仓费，真实、非 bug）。

**三阶段递进**：预期（参考价）→ 修正（成交价）→ 落地（真实结果），分子扣费口径三阶段一致（前两者假设到止盈 $T$、按 $T$ 算费；落地按实际平仓价算费）。三者对比能暴露「预估乐观但落地打折」的问题（如 2026-07-23 阿里 2.30→2.00→0.82R、中芯 3.21→2.20→0.48R，落地远低于预期，根因是没让利润奔跑到止盈就平）。⚠️ 改净口径后**窄止损单赔率下降明显**（港股 18bps 对止损距 0.4 元的单，毛 2.28R → 净 1.95R、降约 14%）、**宽止损单影响小**（美股 3bps 对止损距数元的单、降幅 <3%）——这是真实成本、不是口径 bug，意味着窄止损策略在净口径下 edge 更薄、更要挑高毛赔率的入场点。

## 移动止损总原则

持仓全程移动止损线；当**止损价移过成交价到盈利方向**（做多止损价 > 成交价 / 做空止损价 < 成交价）时，这笔的胜负已锁定（最差不亏）。但**锁定胜负不等于停止移损**——后续仍要随趋势推进持续更新止损位（出现新趋势反转位移到新反转位，或浮盈变大时按「止损单的两种用法」锁更多利），直到动能将竭主动平仓或当日停止盯盘前了结。

## 移动止损：modify 触发价单步（2026-08-05 实测修订，「先新增后撤旧」降级为 fallback）

移动止损 = **把现有活动止损单的触发价 modify 到新止损价**（2026-08-05 实测：开仓附加止损腿 OrderLeg('LOSS') 落成的独立 STP 可直接 `modify_order(aux_price=新价)`，单步、无撤单 race；仓位无活动止损才补下新 STP、modify 失败才 fallback「先下新止损单、再撤旧止损单」）。**保留单个活动止损是硬要求**——防空仓反向开仓：实测（2026-08-01）确证多止损单累积不安全，卖单拦截分两种，① 有持仓时卖超持仓 → Reject「Insufficient holdings」（止损失败）；② **完全空仓时卖 → 被接受**（NotReported）、成交即反向开仓。故多个止损单累积、首个触发平仓后账户变空仓时，其余止损单再触发会**反向开仓**（不是止损失败）。modify 方案天然只有一个活动止损、无累积问题；fallback「先下新再撤旧」时撤旧排除刚下的新止损，确保任意时刻只有一个活动止损、且仓位始终有保护无裸奔空窗。新止损价位于更紧、更有利价位（移损只朝有利方向移）。平仓后不残留止损单（老虎平仓走「modify 触发价=现价」让止损单成交、仅 fallback 撤单 + MO 时才撤）。
## 止损单的两种用法

止损条件单有两种用法，按浮盈阶段选择——不要僵化地只认一种：

- **用法 A：锁大利润（浮盈 ≥ 2R 时）**——把止损移到靠近现价的盈利区。**大概率会触发、被动平仓锁住大利润**，同时给到小概率让利润继续奔跑。**「大利润」基准 = 浮盈至少 2 倍赔率（2R）**（2026-08-01 用户立）：浮盈 < 2R 不算大利润、**不用此用法**（用用法 B 放趋势反转位）；浮盈 ≥ 2R 才考虑锁大利润（大概率锁利落袋、小概率让利润继续奔跑）。
- **用法 B：放趋势反转位（浮盈 < 2R 时）**——把止损放在预期趋势反转点（用 K 线形态判断：前低/支撑、前高/阻力）。**大概率不触发、让利润继续奔跑**，小概率触发（趋势真反转时离场）。适用于浮盈 < 2R（未达大利润基准）、想给趋势充分空间、不愿被小回调扫出去的场景。

两种用法的止损位都要落在有技术意义的价位上，**不要用百分比机械算**（-5% 之类脱离盘面结构、无技术意义），也不要放在盘面噪音区（会被随机波动扫掉）。

### 用法 B 详解：止损放在预期趋势反转位

开仓时定在开仓前后的形态反转位；持仓中只有当盘面出现新的预期趋势反转位时，才把止损移到新反转位——不是因为浮盈来了就移。随趋势往有利方向推进，新的反转位（如抬高的支撑、下移的阻力）常落在成本区或盈利区，此时移损顺带起到「保本/锁利」的效果，但这是结果、不是目的。

**反面教训（2026-07-28 SOXS 做多 63.86）**：止损死守 3x ETF 5%（60.28 = **-5% 百分比机械算、非形态反转位**）+ SOXS 开仓后涨到 64+（趋势推进、应出现新反转位）没移损、之后跌到 60.79、远止损没兜住、手动平在最低 → 亏 $246；若按 K 线形态止损在 62.65（支撑反转位）只亏 $97、若趋势推进后把止损移到新反转位则损失更小（差 $149～$246）。3x ETF 波动大，其形态反转位在价格上天然更远，但仍按结构定、不按百分比。

### 用法 A 详解：浮盈 ≥ 2R 时锁大利润、不只保本（2026-07-08 SOXL 教训）

浮盈 ≥ 2R（2 倍赔率，大利润基准）时，移动止损应放到**盈利区**（锁住部分利润），不只放到成本位（保本）。2026-07-08 做空 SOXL：成本 162.84、浮盈 $96（现价 160.37、2.47/股）时只把止损移到成本 162.84（保本），结果 SOXL 反弹到 162.84 保本出、**$96 浮盈全回吐**。正确做法：浮盈 2.47/股 时止损应移到 **161 附近**（锁利 1+/股 ≈ $39+），反弹触发锁利、不回吐浮盈。原则：**浮盈越大、止损越要往盈利区挪**（保本只是浮盈小时的底线，浮盈大了必须锁利）。

## 锁利大小要动态权衡、不机械固定

浮盈中移动止损，**锁利多（止损紧）= 防回吐但被小反弹扫、错过续顺势的大赔率**（实际剩余赔率降）；**锁利少（止损松）= 让利润奔跑但回吐风险**。不机械「锁 2+/股」或任何固定值，而是**实时预估净剩余赔率（净口径，见「赔率三阶段」）+ 续顺势 vs 反弹概率，动态选锁利位使 EV 最大**。

判据：标的波动大（3x ETF）止损要偏松（防小波动扫损）；大趋势强、续顺势概率高 → 锁松让利润奔跑；超跌、反弹概率高 → 锁紧防回吐。

⚠️ 「让利润奔跑」的终点是**当日停止盯盘前**（美股用户喊停或 16:00 收盘、港股 16:00 收盘；持仓不过夜、不跨交易日等）——持仓在当日停止盯盘前了结。**锁利位是浮盈中持续重估的变量，不是一次定死**。

## 止盈完全靠盘面实时判断

没有固定止盈位，止盈目标价只是开仓前算赔率的预期值，不是要等到那个价位才平。锁利有两个手段：① **主动平仓**——浮盈中一旦**情况不对**（动能减弱、价格停滞不朝持仓有利方向推进、资金流逆转到对持仓不利方向），立即主动平仓；② **移损到盈利区**——把止损单移到浮盈区，被动触发锁利。两者配合，不执着等价格朝有利方向走，否则会把已到手的利润还给市场。

**目标止盈位必须大概率可达（2026-08-03 用户立）**：开仓前定的止盈目标价，必须是**当天大概率能走到的位置**——够不到的目标没有意义。把止盈推到够不着的位置，只会把虚高的赔率送过 1.2 门槛，掩盖「开仓位置过高、当日剩余空间不足」的事实（2026-08-03 反面教训：阿里开仓 125.30 在当日振幅 88% 分位、距当日高 126.0 仅 0.56%，止盈定 130 凑出修正预期 3.6R，实际 130 当天不可达——全天最高就是 126.0，这笔当日可达的真实赔率不足 1R）。可操作的检查三条：

- **止盈位一般不超过当日高点上方小缓冲**：午后突破当日新高的概率天然低，目标越过当日高默认「当天不可达」，除非出现增量信号（放量突破 / 新催化）才考虑上调。
- **开仓价在当日振幅的分位越高，目标越要调低**：越接近当日高，上方剩余空间越小；调低后赔率不足 1.2 的结论是「这笔不做或等回踩」，不是把止盈推远去凑赔率。
- **剩余时间 × 当前速率**：午后量能习惯性萎缩（2026-08-03 阿里午后量比从 3.9 缩到 2.0），单位时间可走的空间远小于早盘，止盈距离不能按全天振幅估。

**午盘动能不足、目标止盈位保守（2026-08-03 用户立）**：一般午后成交量萎缩、增量催化少（隔夜 / 盘前信息早盘已集中反应，港股还受 A 股午后走势联动），价格多进入窄幅消化，假突破多、趋势性动能少（2026-08-03 实测：阿里午后 3 小时振幅仅约 0.4%，07709 / 小米同步缩量窄幅）。故**午盘开仓默认按「动能不足」设保守目标**；例外——午后出现放量突破 / 新催化等增量信号时，按实际盘面动态上调。判断依据永远是量能与突破形态，不是机械的「午盘一律保守」。

## 临近停止盯盘的分情况策略

临近当日停止盯盘时点（港股 12:00 午休前 / 港股 16:00 收盘前 / 美股用户喊停或 16:00 收盘前），**停盯前必须主动平仓，不存在留单**。

主动平仓时机判据：

- **有持仓**——
  - ①**「情况不对」信号**（任一即立即主动平仓锁利）：价格停滞不朝持仓有利方向推进 / 动能减弱 / 资金流逆转到对持仓不利方向 / **加速赶极端**（做多持仓加速赶顶 = 加速上涨 + 破前高 + 远离 VWAP 上方超买；做空持仓加速赶底 = 加速下跌 + 破前低 + 远离 VWAP 下方超卖——两者都是动能将竭）——剩余时间不多，收益一旦跌下去没足够时间涨回，此时主动平锁利。
  - ②**无情况不对信号、趋势仍健康**：可持有到停止盯盘时点前再主动平（让利润多跑一段），但**到停止盯盘时点必须主动平掉**。
- **无持仓**——临近停止盯盘时点开仓要小心：剩余时间少意味着止盈空间被压缩，初始预期赔率可能凑不到 ≥1.2，开仓前必须重算、不足就不开。

一句话：**临近停止盯盘，有仓看「动能是否将竭」决定何时主动平（将竭立即平、仍健康可持有到停盯前），无仓看「剩余时间够不够凑出初始预期赔率」决定开不开**。

## 加速赶极端 = 动能将竭信号（盘中任何时候适用）

不限于临近停止盯盘——**盘中任何时候浮盈大 + 加速赶极端**（做多：加速赶顶 = 加速上涨 + 破前高 + 远离 VWAP 上方超买；做空：加速赶底 = 加速下跌 + 破前低 + 远离 VWAP 下方超卖 = 动能将竭）→ 立即主动平仓 🔴 锁利（2026-07-17 MU 教训：浮盈 +$3071、加速赶顶却误判「持续上涨」、最终回吐 ~$2000；盘中任何时候动能将竭就该主动平、不等停盯）。

## 回踩不破前低 = 最佳平仓时刻

做空时价格**回踩前低不破**（= 下跌动能衰竭、买盘承接站住）→ 这是技术面上最佳主动平仓时刻；做多时回踩前高/支撑不破 = 持有时刻。错过这个点位往往由盈转亏。

## 做多合格入场只有两种

① 回踩支撑企稳反弹（如 2026-07-07 美团 77.50 支撑企稳，+HK$990）；② 突破后回踩阻力转支撑不破。「赌突破」不在其中——前两者依据**已发生的事实**，后者依据**预测**。

⚠️ **暴跌低点（超跌区：单日 -8%+ 或从高点 -30%+）做多「回踩企稳」不适用——必须等双底或头肩底（第二个低点不破前低 + 破颈线确认反转）**：暴跌低点的「企稳」极可能是下跌中继而非反转，「新低 N 次不破」只是支撑测试、不是反转形态；开盘 30 分钟内不在暴跌标的开多（双底/头肩底需时间构筑、6 分钟形不成）。

**反面教训（2026-07-29 07709）**：从高点 -48% 暴跌、开盘 6 分钟用「新低 11 次不破 + 回踩企稳」开多 = 抄在暴跌低点接飞刀，随后跌破新低亏 -1R；正解 = 等双底/头肩底（第二低点不破前低 + 破颈线）再开。

## 多头趋势日：VWAP 上方企稳 = 顺势做多入场点（2026-08-03 美股教训，补「做多合格入场只有两种」）

多头趋势日（**开盘板块全面站上 VWAP + 持续上行 + 买卖比改善**）里，**VWAP 上方企稳 = 顺势做多入场点**——止损放 VWAP 下方（或近期低点）、目标看前高 / 阻力，**不等突破也不等深回踩**。

- **为什么不等突破 / 不等深回踩**：「等突破阻力 / 等回踩 VWAP 企稳」是震荡市或弱市的入场法；多头趋势日里价格走的是「VWAP 上方震荡上行」——既没回踩 VWAP、也没突破阻力，正好卡在传统两个条件中间被漏。多头不回头，等深回踩等不到；不突破不代表没行情，VWAP 上方持续上行本身就是顺势段。
- **与「做多合格入场只有两种」的关系**：本条是它的**第三条补充**（适用场景限定多头趋势日）——回踩支撑企稳（①）、突破后回踩转支撑（②）之外，**多头趋势日的 VWAP 上方企稳（③）**同样是合格入场，因为入场依据同样是已确认事实（站上 VWAP 且不破 = 多头主导的事实），不是预测。
- **与「纪律性不追高」的关系（关键区分）**：同根问题——**没区分「多头趋势日顺势做多」与「普通追高」**。「不追高」指的是在拉伸高点追、远离关键位；多头趋势日里 VWAP 上方企稳顺势做多不是追高——入场点是企稳位（VWAP 上方、买卖比不恶化）、有止损保护、方向顺板块共振，与「高位追多无止损」是两回事。判「追高 vs 顺势」看三件事：① 是否多头趋势日（板块共振站上 VWAP + 持续上行）；② 入场点是否企稳位（非拉伸高点）；③ 止损是否有技术意义（VWAP 下方 / 近期低点）。
- **反面教训（2026-08-03 SOXL/MU）**：美东 11:29（北京 23:29，板块 VWAP 企稳反弹、第 68 段）到 12:08（北京 00:08），SOXL/MU 在 VWAP 上方震荡上行（SOXL 112.11→114.18 +1.85%、MU 807.95→816.27 +1.03%），NVDA 持平 206-207 滞涨。AI **全程错过**、定性「高位震荡无合格入场」——两条根因：① 判断失误，把「VWAP 上方震荡上行」当成「高位震荡无机会」，只盯 NVDA 滞涨、用 NVDA 的「无突破」否决了 SOXL/MU 的顺势上行（盯错了锚：板块共振的方向由全貌定、不由单只滞涨定）；② 入场条件太严，只等突破阻力 / 回踩 VWAP 两类信号，VWAP 上方震荡上行正好卡在中间被漏。
- **边界**：① 本条仅适用于**多头趋势日已确认**（开盘板块全面站上 VWAP + 持续上行 + 买卖比改善）；早盘市况不明朗期（冲高回落未定）仍按「早盘市况不明朗期」条观望——市况性质确定不了就不开仓；② 企稳失效 = VWAP 被跌破（或买卖比持续恶化）即止损出、不等；③ 入场点仍是「VWAP 上方企稳」的顺势位，不在拉伸高点追；④ 3x ETF 波动大、止损仍按形态定（VWAP 下方 / 近期低点），不套百分比。

## 早盘市况不明朗期：开盘约 30 分钟谨慎开仓（2026-08-05 用户立）

开盘约 30 分钟（09:30-10:00）**市况不明朗**——早盘的冲高回落、大跌反弹幅度都很大（流动性集中、情绪波动大、方向未定），这个时间段**谨慎开仓**：

- **冲高后要等回落**：早盘冲高（如 +3% 以上）后大概率回落、幅度大——**不在冲高后的回落中开多**（接回落），等**回落企稳的二次确认**再考虑做多。
- **大跌后要等反弹**：早盘大跌后大概率反弹、幅度大——**不在大跌后的反弹中开空**（接反弹），等**反弹遇阻的二次确认**再考虑做空。
- **市况确定不了就不开仓**：早盘半小时常定不了当日市况（震荡日 / 多头趋势日 / 空头趋势日未明——冲高回落 vs 趋势日未确认）。**市况性质确定不了就观望、不开仓**。
- **频繁重新评估市况**：该时段市况变化快（可能冲高回落转震荡、或确认趋势日），要频繁重估（10 分钟重估 + 更频），不固守开盘判断。

**反面教训（2026-08-05 中芯）**：开盘 31 分钟中芯冲高 +4.7%（65.5→68.6）后回落，我在回落中 10:01 开多 @68.15 = 接回落，开仓后继续回落 67.5（-1.38R）。当时自查看似过（VWAP 上方 + 突破 0.5 + 0.5 回踩企稳 + 板块共振）判「多头趋势日」——但早盘冲高回落 vs 多头趋势日未定（冲高后回落幅度大），判断过早。**自查清单过（VWAP / 形态 / EV）≠ 市况已确定**——早盘冲高回落幅度大、市况未明时形态看似成立也不开，等市况明朗（回落企稳确认趋势 or 确认震荡）再按正常入场。

**与「开盘观察期 = 条件触发」的关系**：条件触发针对「数据稳定」（VWAP 成型、形态构筑）；本条针对「市况性质确定」——两者都满足才开仓。早盘市况未明（冲高回落 / 大跌反弹未定）时，即使数据看似稳定也不开。

## 做空合格入场只有两种 + 反抽破前高放弃做空（与做多版本对称）

① **反抽阻力位乏力遇阻**（下降趋势中价格反弹到阻力涨不动时做空）；② **跌破关键支撑后反抽该支撑遇阻**（破位回抽不过，做空确认）。

**禁止：在下跌低点 / 头肩底等转势形态的头底做空**——那是做多位置，在下跌低点空 = 接飞刀、抄顶抄在半山腰（正好抄在即将转头向上的起点）。

**反抽力度判据（核心）**：反抽力度过大、**破前高 = 下降形态被打破 = 果断放弃做空**（含止损掉已开的空仓），绝不执念。2026-07-21 MU 反面教训：从 945 回落到 916.57（头肩底头底）就在 @917 做空 = 抄在日内下跌最低点 + 逆着头肩底做多形态空；反抽一路破前高 945 到 953（下降形态打破），却持仓死扛，亏 $666。正确做法：① 不在 916.57 空，等反抽到 925-945 阻力乏力再空；② 反抽破前高 945 立即放弃做空。

**「反抽乏力」= 动能衰竭证据链，不是反抽高度（2026-08-03 07709 教训）**：判定「反抽乏力」不看反抽到多高（机械等「接近前高」），看反弹动能是否衰竭的证据：**反抽未到前高就多次测试不过（≥3 次）+ 买卖比转负 + 跌破反弹起点/破位** = 空头信号同样成立（对应②「跌破关键支撑后反抽该支撑遇阻」/ 破位确认空）。2026-08-03 07709（两倍做多海力士，存储崩盘日）：开高 36.88→冲高 37.94→回落 35.60 后反抽，只到 **37.30 就衰竭**（11:05-11:06 买卖比转负 -6/-4），37.0-37.14 **三次测试不过**（37.14/37.14/37.08），11:09 **跌破 37.0 破位**。我却机械等「反抽到 37.5-37.9 才做空」，错过 11:09 破位入场（36.95、止损 37.35 反抽顶上方、止损距仅 0.40=1.1%、初始赔率 3.4 倍、实际到 36.04 = 2.28R、止损全程未触、零风险、错过约 HK$4,380）。**教训**：① 反抽乏力看证据链（多次不过 + 买盘转弱 + 破位），不看价格高度；② 顺趋势入场两条腿并列——等反抽（更稳）与**破位确认（更及时）**，不是二选一；③ **下跌趋势中买卖比转正 ≠ 不能空**：抄底盘接不住（低点持续下移） = 空头延续，破位为主判据、买卖比为辅（与 07-28 兆易「单维度覆盖多维」同款错误）。**边界**：此条仅在反抽衰竭点明确（多次不过 + 破位清晰）+ 止损近（<2%）+ 当日单边趋势时适用；衰竭点模糊、止损过远、震荡市仍应等更稳的入场。

**震荡下行趋势做空位置：上轨反抽做空、下轨附近不追空（2026-08-03 07709 午后教训，用户指出）**：破位确认入场（上条②）**只在单边下跌趋势成立**（破位后空间打开）；**震荡下行通道里，下轨附近破位 = 末端 / 假突破，追空 = 高买低卖的坏位置**。2026-08-03 07709 午后：全天 10:44-15:59 呈标准震荡下行通道——上轨反抽高点依次走低（37.94→36.68→36.08-36.2）、下轨 35.2 四次测试未破（强支撑）。我 15:40 **破 35.6 追空 @35.52**（87,000 股）：距下轨 35.2 仅 0.9%，下行空间只剩 0.32、反弹空间 0.23（止损 35.75），初始赔率仅 1.39 且贴下轨，开仓后 5 分钟反弹回 35.54-35.66，-0.09R 离场。**正确做法**：等反抽上轨（36.08-36.2）做空，止损放反抽高点上方（36.4）、止盈 35.2，赔率约 3.8R，且通道上沿压制反弹、位置天然安全——当日 14:40-15:00 已反抽 36.08，那才是做空位。**核心判别（开空前先问）**：当前是**单边趋势**（破位追空适用）还是**震荡通道**（上下轨多次测试清晰、破位多为下轨末端）？震荡通道里做空 = 等上轨反抽遇阻，做多 = 等下轨回踩企稳，**只在通道边沿交易、不追破位**。与「位置评估硬闸」一致：下轨附近 = 不做空的位置（除「反抽阻力乏力遇阻」明确成立时）。

## 跳空暴涨股的反抽遇阻做空 = 高风险形态（2026-08-04 药明康德教训，加严 07709 跳空教训）

**当日跳空暴涨（+8% 以上）的股票，其「反抽遇阻做空」形态 = 高风险形态——形态对 ≠ 能跌**。跳空暴涨股多头韧性极强：反抽遇阻形态虽然成立（VWAP 遇阻、盘口偏空），但价格跌不动（横盘消化），做空扣双边费后常常打平 / 小亏——「形态对」只说明上方有压制，不说明会跌。

- **为什么**：跳空暴涨（+8% 以上）代表开盘有强大的多头力量（消息 / 资金驱动），这种股当日多头韧性远超常态——反抽遇阻后不是掉头下跌，而是**横盘等方向**（多头惜售、空头不敢追）。做空吃的是「下跌空间」，「遇阻横盘」没有下跌空间、还倒贴手续费。
- **反面教训（2026-08-04 药明康德）**：当日跳空暴涨 +10.8%，三次反抽 VWAP 遇阻做空——形态成立（反抽遇阻 + 盘口偏空），但多头韧性致价格 14 分钟横盘不跌，扣费后 −0.06R（+ 此前 07709 同款教训：逆跳空强势做空「形态对 ≠ 能跌」）。
- **处理（二选一）**：① **要求额外确定性**才出手——跌破今日低（跳空转弱确认）或板块共振走弱（板块级卖压把多头韧性压垮）；② **干脆不做**——等跳空回补（回落当日常态区间）后再按常态做空框架评估。默认取 ②（跳空股当天大部分时间不值得空），出现 ① 的确定性再考虑。
- **边界**：① +8% 是经验阈值，接近但略低于的（+5~8% 跳空）按当日量能 / 资金流是否「多头强驱动」判断，多头驱动强则同样谨慎；② 若跳空股**当日已转弱**（跌破今日低 / 放量下跌确认空头主导）仍可做空——但那是「下跌趋势确认」框架（见「盘中动态修正方向」破位转空），不是「反抽遇阻」框架；③ 本条不放松「反抽破前高放弃做空」——跳空暴涨股反抽破前高 = 多头更强，更该放弃。

## 上升趋势做多位置：下轨（支撑）买、上轨（阻力）卖（2026-08-04 MU 教训，与「震荡下行做空位置」对称）

上升趋势（或 V 反多头趋势日）里做多，位置纪律与震荡下行做空**完全对称**——**下轨（支撑 / VWAP / 回踩位）买、上轨（前高 / 阻力）卖**，绝不反过来（上轨追多 + 下轨杀跌 = 高买低卖）。

- **买点 = 下轨（支撑）**：在**回踩 VWAP / 前阻力转支撑 / 0.382 回撤**等真支撑位做多，不在**前高阻力附近 / 突破后浅回踩**追多。「突破回踩企稳」的「回踩」必须是**深度回踩到真支撑**（VWAP / 前阻力转支撑），不是刚突破的浅回踩——浅回踩仍在阻力附近 = 上轨附近，不是支撑。
- **卖点 = 上轨（阻力）**：在**前高 / 阻力遇阻**或**加速赶顶**时主动平，不在**回踩支撑 / 跌破支撑的恐慌低点**杀跌。跌破支撑后等**反抽阻力遇阻**再平（上轨卖），或严格等止损被动触发，不在恐慌低点卖。

**反面教训（2026-08-04 MU 多单）**：MU 当天 770→829 上升趋势，我 821 做多（接近上轨前高 828）= **上轨追多**（把「突破 820 后浅回踩 820.53」当「回踩企稳」，实际 821 是高位 / 上轨，不是支撑）；MU 跌破 820 后我在 818.6 恐慌平（接近下轨 816 止损）= **下轨杀跌**。完美高买低卖，−0.50R。正确做法：① 买点等**回踩 VWAP 802 / 0.382 790**（下轨）企稳做多，不在 821 上轨追；② 卖点在 MU 冲前高 828 遇阻 / 加速赶顶时主动平（上轨），不在跌破 820 的恐慌低点 818.6 卖。

**与「震荡下行做空位置」对称**：震荡下行 = 上轨反抽空、下轨不追；上升趋势 = 下轨回踩多、上轨不追。**两次都在趋势的错误一端交易 = 两次高买低卖**（2026-08-03 07709 震荡下行下轨追空 −0.09R、2026-08-04 MU 上升趋势上轨追多 −0.50R）。

**判别（开仓前先问）**：当前是上升趋势 / 震荡上行通道？→ 做多等**下轨回踩企稳**（VWAP / 支撑），不追上轨（前高 / 阻力附近）；卖点等**上轨遇阻 / 加速赶顶**，不杀下轨（支撑 / 恐慌低点）。与「位置评估硬闸」一致：上轨附近（前高阻力）= 不追多的位置（除非深度回踩到下轨）。

## V 反趋势日的两段式应对（2026-08-03 MU 教训）

开盘暴跌后 V 反大涨（龙头持续创新高 + 跟风股站上 VWAP）= 多头 V 反趋势日。**开盘暴跌段与 V 反确认段必须用不同框架，不能用同一种**（用开盘暴跌的空头框架去应对 V 反后的多头段，必踏空或逆势）：

- **① 开盘暴跌段（不抄底，也不空反弹）**：跳空暴跌的恐慌急跌点不抄底做多（接飞刀防护，等双底/头肩底确认）——这条对、不放松；**同样不在暴跌后的反抽中做空**——暴跌后的反抽力度常超预期（V 反），「反抽乏力做空」框架会被 V 反直接打破（反抽破前高 = 下降形态失效，见上「反抽破前高放弃做空」）。

- **② V 反确认段（积极做多，不观望）**：一旦 V 反确认（**龙头持续创新高 + 跟风股站上 VWAP** 共振 = 趋势反转、非死猫跳），方向假设立即切做多，在**回踩 VWAP 企稳 / 突破回踩**（浅回踩也算合格入场）积极做多——**不执着「等深度回踩」空仓观望**。强趋势日板块直涨、不深回踩，等完美深度回踩 = 全程踏空。

**V 反确认判据（反转 vs 反弹）**：① 龙头连破 ≥2 道前高（见「反弹vs反转判定」）；② 跟风股站上 VWAP 并企稳。两者共振 = 趋势反转、应做多；只有龙头强但跟风没站上 VWAP = 可能死猫跳、观望。

**反面教训（2026-08-03 MU）**：半导体开盘暴跌（MU -5.7%、SOXL -10.7%）后 V 反大涨——NVDA 龙头从 21:38 起持续创新高（197→…→207）、MU/SOXL 站上 VWAP。我两段都错：① 暴跌段用「反抽乏力」做空 MU @783.19，被 V 反打破止损 −0.92R（逆趋势）；② V 反确认后仍套「不追高、等深回踩」保守框架，没在 MU 回踩 VWAP 801 企稳 / 突破 800 回踩时做多，全程踏空（MU 770→829 +7.6%、SOXL 102→117 +14.5%）。**根因：没把「龙头持续创新高」当作趋势确认信号，开盘暴跌的空头框架整段没切换到 V 反后的多头框架**（与「暴跌日方向由 VWAP 定、不由新闻定」同源——方向由分时结构定、不由开盘暴跌的存量预设）。

**边界**：① 「V 反确认段积极做多」≠ 追高——在回踩 VWAP / 突破回踩等关键位做（合格入场），不在拉伸高点追；② 龙头创新高但跟风没站上 VWAP = 板块未共振，等跟风确认再做多；③ 做多仍走「回踩企稳 / 突破回踩」形态（与「做多合格入场只有两种」一致），不赌突破。

## 持仓中识别对己不利的转势形态要主动止损

持仓后不能只盯价格和资金流，还要持续画低点 / 高点结构识别转势形态——**做空持仓若现头肩底 / 双底（做多形态）、做多持仓若现头肩顶 / 双顶（做空形态）= 形态对己不利，主动止损**，不等资金流全面逆转才动。

配合资金流镜像判据（见下「资金流 > 盘口」条）：**资金流出但价格抗跌不跌 = 买盘承接强 = 反弹临近**，做空持仓遇此应止损。2026-07-21 MU：10:22 右肩形成（头肩底成型）+ 10:26 资金流出但价格抗跌（922 不破前低反抽到 924），此时平仓 @924 仅亏 $252，比死扛到 10:45 平 @937 亏 $666 **少亏 $414**——错失的最佳止损点。

⚠️ **连破小阻力也是转势信号、要主动平**：持仓中标的**企稳后连破 ≥2 道小阻力**（如 MU 7-28 从 810 连破 815/818/820）+ 板块同步走强 = 转势延续，**不等「破前高」机械触发**就主动平。2026-07-28 SOXS 做多：MU 11:19-11:25 ET 连破 815/818/820（转势明确、SOXS 从 63.5 跌到 62.06），我却机械等 824.5 破前高才平（11:47 SOXS 60.79），**多亏 $102～209**（11:19 平亏 $37、11:25 平亏 $144、实际 $246）。这是「盘中动态修正方向①连破≥2道阻力」在**持仓管理**的应用——开仓后也要持续调用、不只盯止损位/前高（与 7-27 MU「规定在 skill 里却没调用」同款执行病）。

## 转势形态：头肩 / 双底双顶（做多/做空入场形态判据）

核心原理——**打破下跌趋势（高点更低 + 低点更低）= 转多信号；打破上涨趋势（高点更高 + 低点更高）= 转空信号**。形态分有头 / 无头两类，原理一致：

- **头肩底（做多，有头）**：下跌趋势中「左肩低点 + 头（更低低点）+ 右肩低点与左肩接近持平」+ **破颈线**（左右肩之间的短期高点）→ 做多信号。
- **双底（做多，无头）**：两个接近持平的低点（中间无更低低点）+ 破颈线 → 做多信号（「低点不再更低」= 趋势被打破）。
- **头肩顶（做空，有头）**：上涨趋势中「左肩高点 + 头（更高高点）+ 右肩高点与左肩接近持平」+ **跌破颈线**（左右肩之间的短期低点）→ 做空信号。
- **双顶（做空，无头）**：两个接近持平的高点 + 跌破颈线 → 做空信号。
- **关键**：用 **close 价**判「持平」（高低点波动大、close 稳）；「持平」= 趋势被打破的核心信号。
- **价值**：比「连破 2-3 道阻力/支撑」更早确认转势——形态在「右肩 / 第二底形成 + 破颈线」一刻即确认。2026-07-17 MU 实例：下跌段 09:37 high 824→09:39 high 815→09:45 low 804（高点低点递降）；**09:41 close 812.19（左肩）+ 09:44-45 low 804（头）+ 09:46 close 812.39（右肩与左肩持平）+ 09:47 回踩 809.79 + 09:48 破颈线 815** → 头肩底确认、做多信号；之后 MU 816→845（+29 点）。比我昨天等连破 836/840/853（11+点）早 1.5 小时。

## 量价正向确认作为开仓前置（借鉴 Livermore 量价法则）

上面「资金流入但价格不涨 = 卖盘更强」讲的是**背离**（资金进但价不涨 = 卖盘在出货，离场信号）；这里补**正向配合**（开仓确认信号）：顺势**做多要求放量**（上涨带量 = 买盘真主动）、**做空要求放量下跌或缩量反弹**（下跌带量 = 卖盘真主动）。**无量突破不可信**——价涨但量没跟上多半是诱多，不追。开仓前看一眼近几分钟量价是否配合，不配合就等。

## 不在关键点之外追单（借鉴 Livermore 关键点法则）

与「做多合格入场只有两种」呼应——那条讲**在哪入场**（回踩支撑 / 突破回踩），这条讲**为何不追远离关键位的拉伸**：价格已远离关键支撑 / 阻力位（涨了一大段没回调 / 跌了一大段没反弹）时**不追**，因为此时 EV 变差——① 离止损位远 → 仓位被迫缩小或止损被迫放松；② 拉伸越大 → 均值回归概率越高 → 胜率下降。等价格回到关键位附近（回踩 / 反抽）再进。一句话：**只在关键位附近交易，远离关键位不追**。

## 事后结果不反推决策对错

评判一笔交易看「当时依据是否站得住」，不看事后盈亏。2026-07-07 第二笔事后看美团摸到 78.50，但中途 77.45 接近 77.90 止损、大概率被扫，依据（赌突破）本就不成立 → 决策错，与事后无关。

## 入场要「已确认」而非「预测」

赌突破 / 赌反转的标的若回落会放大损失。入场点应建立在已发生的事实（企稳 / 真站稳）上。

## 方向大于风控

逆势交易风控再细也难赚。建仓前必看近 5 日 K 线趋势，只在上升趋势回踩或下降趋势反抽时顺势入场，不接飞刀。

## 市场结构：资金流 > 盘口 > 分时（真实性排序，非「只盯资金流」）

盘口墙可造假（挂大单压价/闪挂闪撤），但持续的大单净流入要真金白银、难造假。**盯盘看资金流默认走富途 `get_capital_flow`**（含 super 超大单 + 分钟序列）。盘口偏空但大单持续净流入 → 倾向「洗盘」持有；盘口强但大单净流转负 → 警惕「对倒出货」。判别假/真盘口墙：连续 2-3 轮采样（每轮 30-50 秒）观察是否「持久挂单 + 价格真涨」 vs 「闪挂闪撤 + 价格不动」。

⚠️ **「资金流 > 盘口」是「真实性排序」（已成交难造假 > 挂单可撤），不是「只盯资金流就够」**——三者是「领先-验证-形态」互补关系：**盘口（挂单）领先但可假、资金流（成交）验证但滞后、形态（K 线结构）看转势**，盯盘必须三维度结合、不能只盯资金流一个维度。

**资金流与价格的镜像判据**：资金流入但价格不涨 = 卖盘更强（看空，2026-07-07 美团）；**资金流出但价格抗跌不跌 = 买盘承接强（看多）**——做空持仓遇此应警觉反弹临近、考虑止损。2026-07-21 MU 反面教训：10:26 只盯「总资金流出 −6004 万」就判偏空持仓，忽视盘口（价格从 916.57 抗跌反弹到 924 = 买盘承接）和形态（头肩底右肩成型），错失止损点。

## 总资金为主、super 为辅（纠正「盯 super 做决策」毛病）

判断市场多空合力看**总资金流向**（super + big + mid + small 净流向 = 所有参与者合力 = 价格推动的真实总力），**不是盯 super 单**——super 只占总资金约 4%（2026-07-21 MU 实测：10:26 super −216 万 / 总 −6004 万 = 3.6%、10:59 super +798 万 / 总 +17263 万 = 4.6%），盯 super 的细微起伏（−535→−216 这种单笔大单随机结果）是见树不见林、把噪音当信号。

**super 的正确用法**：只看「持续大幅趋势」（如 super 连续大幅净买 = 机构吸筹，配合「大单吸筹 + 缓慢震荡上涨时不过早平」条），**不看细微波动**。⚠️ 总资金含大量散户小单（情绪化、跟风），暴涨日散户追多会推高总资金净流入，故主信号是**总资金 + 价格的关系**（共振 / 背离，见上「资金流与价格镜像判据」），super 作机构动向辅助参考。2026-07-21 MU 反面教训：反复解读 super（−535→−216→−680→−13→+798）当主信号，10:26 本应看「总资金大幅流出 −6004 万 + 价格抗跌」的背离（= 买盘承接），却盯 super 减缓持仓，错失止损。

## 资金流入但价格不涨 = 卖盘更强（最高优先级）

资金流（capital inflow）只有伴随**价格同步突破**才是多头确认。若资金持续流入但价格多次冲阻力不过（价量背离），说明上方卖盘在出货、把买单全吃了——这是**离场 / 观望信号，不是入场信号**。2026-07-07 美团第二笔误把「资金流入」当成「突破在即」，七次冲 78.50 失败，亏 −HK$125。

## 阻力三次不过不赌突破

一个阻力被测试 ≥3 次都不破 = 强阻力确认，下次突破概率随测试次数**下降**（不是上升，每次失败都在验证卖盘强度）。想做多就等「真放量突破站稳 + 回踩阻力转支撑不破」，不要在阻力下方提前埋伏赌突破。

## 大单吸筹 + 缓慢震荡上涨时不过早平

super 超大单持续大幅净买 + 价格**缓慢震荡上涨**时，super 短期波动（停止活动 / 略降）≠ 反弹结束，不要一见 super 略降就判「动能衰竭」平仓。**离场判据**（任一即可）：① super **真正持续转流出**（大单出货）；② 价格**跌破关键支撑**（如当日低点）；③ **阻力多次不过 + 量缩**（动能真衰竭组合）。super 持平 / 略降但未转流出时倾向持有（让大单吸筹的后续拉升兑现）。

⚠️ **场景限定——按上涨速度区分**：本条只适用**缓慢震荡上涨**（持有）；若标的处于**急速上涨（加速赶顶）**则应提早平、不抓顶部（急速反转风险，见「加速赶极端」条），不能套用本条「持有等 super 转流出」。

## 三角形持续形态未破时持有 / 移损观望、不因遇阻就平（细化「阻力三次不过不赌突破」）

三角形持续形态**未破**时，即使阻力 / 支撑多次遇阻也应**持有 / 移损观望**，不因遇阻就平——**阻力 / 支撑多次遇阻 ≠ 反向信号**，要结合形态斜率判断：遇阻 + **形态破**（支撑 / 阻力线斜率反转）才反向；遇阻 + **形态未破** → 持有 / 移损观望、等突破。形态判据（做多 / 做空对称）：

- **上升三角形（做多持仓）**：底部支撑线正斜率（低点抬高）+ 顶部阻力线走平（高点不创新高但不回落）+ 夹角向上收敛 → 僵持后大概率**向上突破**。
- **下降三角形（做空持仓）**：顶部阻力线负斜率（高点降低）+ 底部支撑线走平（低点不再更低）+ 夹角向下收敛 → 僵持后大概率**向下突破**。
- **怎么用**：形态未破时 ① 不平仓；② 移损跟随形态（做多止损跟随支撑抬升、做空跟随阻力下移）；③ 观望等突破。突破后的急速段按「加速赶极端」提早锁利、不死等；反向回落破形态则移损止损出。

⚠️ 本条细化「阻力三次不过不赌突破」——单看阻力次数不够，要结合形态斜率：**形态未破时的遇阻 = 持有信号，不是反向信号**。

## 区间震荡市要切换区间交易、不执念破位做空（最高优先级）

当价格在区间反复（如 SOXL 162-170 **多次假破位 / 假突破**），说明是**区间震荡**而非趋势——多次假破位本身就是「支撑有效」的信号。此时强支撑（多次测试不破）= **做多信号**（向阻力看，赔率好），强阻力 = **做空信号**（向支撑看），**而不是等破位顺势**。

2026-07-08 SOXL 162 三次假破位都反弹，162 是强支撑、应在 162 做多（止损 160、止盈 170、赔率 4；实际反弹到 168 +3.7%），但我执念「板块弱做空」、反复等破 162 做空（三次假破位全错过 + 一笔保本）。教训：**≥2 次假破位/假突破 = 区间信号，立即切换区间交易（支撑买 / 阻力卖），不执念单一方向**；「二次确认避免假破位扫损」是对的，但更要从假破位读出「支撑强→可做多」。

## 震荡市策略（3 类动作框架）

震荡市里移动止损锁利不好用（价格反复触及止损位被扫），改用主动平仓锁利 + 回到支撑位重新开仓。做多持仓：区间上沿阻力位 → 主动平仓 🔴 锁利；区间下沿支撑位 → 重新开仓 🟢。做空持仓对称反向。重新开仓必须带止损——支撑被突破时必须止损，不能死扛。

## 震荡市策略失效应对：前置识别市况 + 减少出手（2026-08-04 复盘立，假设待样本验证）

策略本质是「**趋势日 / 暴跌顺势大胜捕获器**」——edge 来自捕捉单边大波动日的 ≥2R 大胜（4 笔 ≥2R 大胜全部集中在 7-17~7-21 半导体单边波动期、占总 R 和的 170%）。震荡 / 无趋势市况天然不适配：大胜来源消失后，剩下「赢得薄（典型中位数 +0.03R）+ 偶尔止损（−1R 上下）」的交易，扣费后整体转负（8 月以来近 10 笔 EV −0.29R、胜率 30%，N=38 复盘观测）。

**震荡市应对三件事（按优先级）**：

1. **前置识别「趋势日 vs 震荡日」，震荡日减少出手**：开盘后判行情性质（`monitor_summary.py` 全貌摘要的行情性质判别 + VWAP 方向，见 `references/monitoring.md`「VWAP 必看」）——判为**震荡日**（箱体反复、无持续单边、VWAP 横盘）时**出手频次减半、只做区间边沿的高确定性交易**（区间上沿阻力 / 下沿支撑 + 🟢 高置信 + 赔率厚——按「预估赔率系统性打折」×0.5 折扣后仍 ≥ 1.2），其余空仓观望、不追低质量机会；判为**趋势日**（VWAP 持续单边 + 板块共振 + 买卖比改善）维持正常出手。**与「区间震荡市要切换区间交易」衔接**：那条讲「震荡市里怎么做」（支撑买 / 阻力卖、不执念破位），本条讲「震荡市里做多少」（减少频次、只做高确定性边沿）——两者叠加，震荡市整体是「少做精做」。
2. **改进小赚小亏出场，避免扣费后转负**：净口径下「毛盈利薄」的单最容易被双边费吃成负（8-04 药明毛 +90 被费 196 吃成净 −106、HK.09988 毛 0 被双边费 7,560 打成 −0.30R）。两类修正：① **窄止损单从严**——港股止损距 < 1.5% 的单 edge 极薄（18bps/边 × 双边费占止损额比例高），开仓时按 ×0.5 折扣后的赔率从严重估（与「预估赔率系统性打折」叠加，不达标不做）；② **小赚不过早止盈、小亏不拖延**——浮盈 < 2R 按「止损单两种用法」的用法 B 放趋势反转位、让利润有机会奔跑（保本就平 = 毛盈利被费吃光），接近止损位则按纪律走、不靠「再等等反弹」拖延。
3. **趋势日敢捕捉（另一面，防识别错方向）**：edge 在趋势日——趋势日确认后按正常框架积极开仓（VWAP 上方企稳顺势做多、暴跌顺势做空），**不在趋势日里套震荡日的小心尺度**；把趋势日误判成震荡日同样是输（2026-08-03 美股 VWAP 上方震荡上行整段被漏的教训）。

**边界（严谨性）**：
1. 「策略本质是趋势日捕获器」「震荡市天然不适配」是 **N=38 复盘观测 + 假设**（8-04 复盘明确标注待更多样本验证），当前应对是「结构性克制」而非「已证伪」——市况判断错、或样本扩大后假设不成立，以新数据为准；
2. 减少出手 ≠ 停手：震荡日里区间边沿 + 高置信 + 折扣后赔率仍厚的交易照做（区间交易本身有正期望时），只是不追低质量机会；
3. 窄止损从严不动止损位定法：形态位（趋势反转位）该多近就多近，「从严」体现在「这种单要么赔率厚到折扣后仍过门槛、要么不做」，不在止损位上人为放宽 / 收窄。

## 开仓要等回踩不破支撑

不追在突破点。强势突破不给回踩则放弃，宁错过不追高。

## 没有明确顺势信号时宁可空仓

不为扳回亏损强行交易（「最大化收益率 ≠ 最大化交易次数」）。

## 连亏不是停手理由，机会不合格才是

AI 无情绪干扰，两连亏后不带「扳回」执念、仍按「顺势 + 资金流 + 主动止盈」纪律执行，有正期望（2026-07-03 前两单逆势亏 -301，后两单顺势 +66 扳回 22%）。

## 杠杆 ETF 反弹强且久，斐波那契 0.5 回撤不是顶

2x 杠杆 ETF 超跌反弹力度大、持续久，判「反弹遇阻」不能在 0.5 回撤位（50%）就下结论，要等 0.618（61.8%）甚至 0.786 / 前高附近**多次测试不过**才算遇阻（与「阻力三次不过」同理）。2026-07-10 做空 07709（两倍做多海力士）：跌势 98.86→90.68（区间 8.18），0.5 位=94.77、0.618 位=95.74；反弹到 94.6（0.5 位）我就喊遇阻，实际穿透 0.5、0.618 一路到 **97.50（83% 回撤）**。过早判遇阻 → 踏空或被扫。**回撤位算法**：位 = 低点 +（高点−低点）×比例（0.5 / 0.618 / 0.786）。

## 止损位与入场点是 EV 综合权衡，不是「止损越远越安全」

做空时止损近=赔率高但胜率低（易被反弹扫），止损远=胜率高但赔率低。必须按 EV=胜率×赔率−败率×1 综合判，不能只看赔率或只看「不被扫」。

2026-07-10 07709 在 94 做空：止损 96 赔率 2.5 但胜率≈0（午后 97.5 必扫，EV=−1）；止损 99 胜率 85% 但赔率仅 1.0（EV=+0.7 薄）——差入场点上怎么选止损都别扭。**正解是等更好的入场点**：午后 97.5 遇阻做空、止损 99、赔率 5.7、胜率 80%（EV=+4.36），「止损近且不被扫」与「赔率高」同时成立。核心：**找高胜率 + 高赔率同时成立的入场点，而非在差位置纠结止损远近**。

## 杠杆 ETF 的止损位天然更远（但同样按两种用法，不套百分比）

**止损位用「止损单的两种用法」框架定，不论什么标的**——用法 B 放趋势反转点（形态支撑/阻力、VWAP），用法 A 浮盈 ≥ 2R 时锁大利润移到盈利区。3x ETF 波动大，其趋势反转位在价格上天然更远——这是形态结构决定的，不是人为加百分比；但不管哪种用法，3x ETF 的止损位都比普通标的更远（反转位本身更远 + 噪音区更宽，止损太近必被扫）。3x「分散个股风险」是错觉：分散只降单股特质风险、但 3x 把整体市场风险放大 3 倍，净波动率 ≈ 板块×3 > 单股（SOXL 振幅 9.2% vs MU 4.4%），**风险控制靠止损位定在合理价位、不靠标的分散**；下单前核实代码 + 流动性。

**【2026-07-13 第一单，做空 SOXL 40 股 @ 171.82、止损 173.5】**：SOXL 173 阻力三次不过、MU 冲 932.99 回落 929（看似失败新高）时入场，但 MU 随后继续创新高 936.47，带 SOXL **持仓仅 50 秒**即冲破 173.5 止损，亏 $81.7。教训：① **领先指标持续创新高时不做空主标的**（见下条），等领先指标明确见顶（连续 ≥2-3 轮不创新高 + 买卖比持续负）再空——这条优先级高于 ETF 自身的阻力确认；② **「失败新高」判断要严**：单次冲高回落 ≠ 见顶，需连续多轮确认（与「杠杆 ETF 反弹强且久」同理，反弹 / 强势持续力易被低估）；③ **3x ETF 急涨时市价止损有滑点**（本单 173.5→173.8625，+0.36 / +0.21%），止损位预留滑点 buffer、或 max_loss 预算计入滑点（本单超 $80 预算即因滑点）；④ **纪律一致性**：盯盘中前几轮因「MU 强不空」反复放弃做空，这一轮 MU 仍强（932）却破例空——临场不为「想开仓」而放宽自己立的标准。

**【2026-07-13 第二单升级，做空 SOXL 30 股 @ 173.41、止损 174.5，累计两单亏 HK$899】**：**已遵守①**（等 MU 连续 4 轮不破 940.45 才空），但 MU **再次创新高 943.50**、SOXL 33 秒涨破止损，亏 $33.6。教训升级：① **「连续 N 轮不创新高」也不是见顶充分条件**——强反弹市领先指标震荡整理后会再突破，「不创新高 N 轮」只说明短期整理、不说明趋势反转；见顶须确认**明确转跌**（连续阴线 + 跌破前回调低点），非仅「不创新高」；② **强反弹市（暴跌后 V 型反弹）不做空反弹**——反弹力度反复超预期（SOXL 165.6→177.66 +7.3%），做空反弹策略本身在高波动反弹日失效、反复被扫；③ **做空等下跌趋势确认**（标的破前低 / 关键支撑、反弹明确结束），不抢反弹顶部（抢顶 = 赌反转、胜率低）；④ **上涨途中做空执行价变差**：触发点 SOXL 171.57 → 实际成交 173.41（3 分钟续涨 1.84），反弹中做空越拖越不利（执行延迟 + 价格本身续涨，非 AI 反复 quote）。

**【2026-07-14 次日复盘修正——方向其实对，核心是止损位定得太近（没用趋势反转点）】**：次日查 SOXL 7/13 完整 K 线：开 174.61 / 高 177.67 / **低 161.55** / 收 165.37——SOXL 下午确实大跌、破前低 165.6 到 161.55，**两单做空方向完全正确**。若不止损持有到收盘 / 最低，本可盈利 $499-766（HK$3890-5974），实际亏 $115（HK$899）全因止损被盘中反弹扫。**核心失误是止损位定得太近**：单1 止损距离 0.98%、单2 0.63%——这个距离远小于 SOXL 的趋势反转位（形态支撑本应在更下方），相当于把止损放在了噪音区，方向对也必被盘中反弹扫、拿不住。**教训：止损要放在有技术意义的价位（想博趋势就用反转位、想锁利就用盈利区有意义位），不要放在噪音区、也不要套百分比**。⚠️ 上方②「强反弹市不做空反弹」修正为：**做空反弹方向可对，关键是 ①止损放在真正的趋势反转位（不被盘中噪音扫）②入场等反弹结束 / 破位确认、不在反弹途中空 ③转破位空后要耐心等破位（本日收工太早 11:51 美东，错过下午跌破 165.6 到 161.55 的破位机会）**。

## 领先指标持续走强时不做空主标的

做空 ETF 时，其重仓成分 / 领先指标（如 SOXL 之于 MU/SNDK）是方向驱动。**领先指标持续创新高时，ETF 阻力即使「三次不过」确认也会被突破**——领先指标强势是破阻力的动能，机械套用「阻力三次不过」会吃亏。详见上方「2026-07-13 SOXL 第一单」教训①。

## 找标的必须先过热度榜

凡是用户让「找 / 选 / 筛交易标的」或问「有什么可做的 / 看看机会」，**第一步必须跑富途 `get_hot_list(market)` 热度榜**筛选，**不许凭下方关注列表或 AI 记忆直接定标的**。流程：热度榜头部 → 叠成交额 / `volume_ratio` 筛流动性 → 叠顺势过滤（近 5 日趋势）→ `static` + `classify_hk_security.py` 核实代码与类型 → 才进入分析。

**备选关注列表（仅作热度榜之外的参考，不作直接选标的依据；会变，下单前必须核实）**：半导体存储链——海力士 / 三星电子杠杆 ETF、美光科技 MU。

**热度判断方法**：富途 `get_hot_list(market)`（热度榜，关注度+资金维度）比 `get_top_movers_rank`（纯涨幅榜）更靠谱；选热度标的必须叠 `volume_ratio`/成交额筛流动性，排除「振幅高但盘口薄」的小盘题材（实测港股涨幅榜 02526 振幅 283% 那种 = 陷阱区）。热度榜头部 + 流动性好 + 顺势 = 高效机会。实测美股热度榜头部为半导体存储链 MU/SNDK/NVDA/SOXL。

⚠️ **杠杆/反向 ETF（2x）合规**：形态是 ETF、但内部用衍生品实现杠杆，与「禁衍生品」护栏有张力 → **已确认允许（含 3x 如 SOXL）**，下单前核实代码 + 流动性即可。

## 盘中动态修正方向（5 触发条件，最高优先级）

开盘方向研判是「起点」不是「全天锚定」——盘中必须随趋势演变动态校准，方向变了就切换策略，**绝不固守开盘方向执念**。反转触发条件（任一满足即重估方向）：

1. **连续突破 ≥2 道关键阻力**（创新高）= 趋势转多信号，不是「反弹遇阻」——放弃做空框架、转向做多/观望。
2. **连续跌破 ≥2 道关键支撑**（创新低）= 转空，放弃做多。
3. **标的站上/跌破 VWAP 并企稳** = 日内多空转换。
4. **箱顶/箱底 ≥2 次假突破/假破位 = 震荡市确认**（既非趋势延续、也非反转，是区间反复）——立即切**区间交易**（箱顶卖/做空、箱底买/做多），**丢掉「等突破/破位」的趋势执念**（震荡市执念突破 = 把区间当趋势，必踏空）。
5. **持续单向缓慢运动 ≥1 小时但未破关键位**（如持续阴跌后低位缓涨、或持续上涨后高位滞涨）= 动能可能在转向——重估「是否在构筑反弹/企稳」或「是否在构筑顶部」，**不能因「没破关键位」就继续守原方向**。

**判别时机**：每隔 10 分钟重估时自问「箱顶/箱底今天第几次测试了？每次到顶/底是不是都回头？」——顶/底各被测试 ≥2 次都回头 = 震荡确认。
