# 复盘与评估方法论（详细参考）

> 本文件是 trade skill `SKILL.md` 的复盘 / 评估详细方法论。盯盘时不加载；**收到用户明确的复盘指令时读取本文件**，按此逐项统计与评估。SKILL.md 只保留复盘触发条件、工具入口与读图纪律。

## 复盘分析（收到用户复盘指令时做，2026-07-16 立）

**触发**：只在收到用户明确的**复盘指令**时做。盯盘期间专注盯盘、**不自主复盘**（见「信号模式总则」第 5 条）。**所有数值用 Python 实算，不心算报数**（遵守「第一原则」）。

**数据源（2026-08-03 用户立：复盘所有交易 = signals/ + actions/ 两个目录的全部记录）**：复盘数据源 = 项目根 **`signals/` + `actions/` 两个目录下的全部交易记录**——`signals/`（港股 `signals/YYYY-MM-DD-HKT-signals.md`、美股 `signals/YYYY-MM-DD-ET-signals.md`）记 signal 模式信号事实（港美分开记），`actions/`（港股 `actions/YYYY-MM-DD-HKT-actions.md`、美股 `actions/YYYY-MM-DD-ET-actions.md`）记 auto 模式实际成交动作（含 order_id、成交价）。**按批次拆笔**：开仓 🟢 / 加仓 🔵 记录含 发信号时间、标的、批次、方向、量、参考价、止损、止盈、单笔预算、预估 max_loss、置信度、依据；该批次的 减仓 🟠 / 平仓 🔴 / 移损 🟡 记录含 针对批次、参考价、理由。复盘按批次逐笔算参数（入场价、止损、盈亏、R-multiple）。⚠️ 防重复计数：同一笔交易只计一次——signal 与 auto 交易各记各的目录、互不重叠；若同一笔两处都有，以 `actions/` 实际成交记录为准；开仓失败 / 撤销 / 作废批次不计样本（记录上有明确标注）。⚠️ 全量对账纪律（2026-08-03 教训）：此前美股样本曾遗漏 3 笔（07-21 MU 空 / 07-23 MU 多 / 07-28 SOXS 多，样本 N 由 28 → 33、EV 由 +0.606R 修正为 +0.498R、频率派 CI 由全正退回跨 0——漏样本造成幸存者偏差），**每次复盘必须遍历两目录全部文件、与现有 trades.csv 逐日对账，不许只补增量**。

**复盘产物存放（`reviews/`，2026-07-21 立）**：复盘报告与配套数据/图统一放项目根 `reviews/`——主报告 `reviews/YYYY-MM-DD-review.md`（港美混合复盘直接用此；港美分开复盘仿信号文件加 `-HKT`/`-ET`）+ 同日附件 `reviews/YYYY-MM-DD-*.{csv,png}`（输入数据 CSV、统计图）。**`reviews/` 是事后复盘分析的存放处，与 `signals/`、`archive/` 三者分工**：`signals/` 记信号事实（复盘的数据源，只记事实不写分析、避免污染复盘数据源）；`reviews/` 放今后复盘分析；`archive/` 留更早的历史归档（含旧复盘，如 `archive/2026-07-06-sim-review.md`、`archive/2026-07-17-ET-review.md`，不再向其新增复盘）。目录说明见 `reviews/README.md`。

**复盘工具（`scripts/review.py`，2026-07-21 立）**：复盘直接跑 `python3 scripts/review.py <trades.csv>` 一次性输出全套指标——样本明细、终局统计量（胜率 / 败率 / 胜赔率 / 败赔率 / EV / EV%）、过程指标分盈利单 / 亏损单、贝叶斯 P(EV>0)（NIG，t 后验）+ σ 不确定下敏感性区间、频率派 EV 95% CI、样本量规划。输入 CSV 字段与示例见 `scripts/review-input.example.csv`（`date / symbol / direction / entry_price / exit_price / shares / max_loss`，可选 `raw_high / raw_low`）；`raw_high / raw_low` 缺失则跳过过程指标。⚠️ 算过程指标的持仓期间 high / low 需从富途分钟 K 按开 / 平仓时间戳回拉（signals 记录只有端点价、无期间 high / low），或平仓时原生记 `mfe_R` / `mae_R` 后补进 CSV。

**每次复盘必含序贯贝叶斯 P(EV>0) 演变图（2026-07-23 用户立，复盘必含项）**：每次复盘报告必须包含一张**「完整贝叶斯 P(EV>0) 随历史所有交易时间顺序逐笔累积」的折线图**——横轴是交易序号（按开仓时间排序、含本项目全部已平仓交易），纵轴是 P(EV>0)%；图上必须画**三条线**：① **点估计**（每加一笔交易后累积算出的 P(EV>0)）；② **下界**（σ 不确定区间的下端）；③ **上界**（上端）——即点估计 + 区间估计的下界、上界共三个点对应三条线（下界与上界围成不确定带）；另附 50% 中性线与 95% 确认阈值线作参照。算法用完整贝叶斯 NIG（t 后验，与 review.py 一致），每加一笔交易重算后验记一个点（N=1 算不出 σ、从 N=2 起画）。图存 `reviews/YYYY-MM-DD-bayes-evolution.png`、嵌入复盘报告，并配关键节点数据表（N / 交易 / 本笔 R / 累计均值 / P / 区间）+ 分阶段解读（探底 / 转折 / 攀升）。**为什么必含**：单次复盘的 EV 点估计看不出「证据是怎么累积起来的」——序贯图能看出信念的探底、转折、攀升全过程，以及当前点估计相对区间下界的稳健度（点估计高但下界低 = 运气成分大、不可确认）。画图脚本见 `scripts/bayes_evolution.py`（复用 review.py 的 `bayes_nig` / `sigma_ci` 函数 + matplotlib），每次复盘更新该脚本的历史交易数据后重跑。

**每次复盘必含序贯 EV 演变图（2026-07-23 用户立，复盘必含项）**：除上方 P(EV>0) 演化图外，每次复盘报告还必须再含一张**「累计 EV（R 倍数）随历史所有交易时间顺序逐笔累积」的折线图**。这张图与 P(EV>0) 演化图**同源**——同一组按开仓时间排序的全部已平仓交易、同一横轴（交易序号）；区别只在纵轴：P(EV>0) 图纵轴是概率%（回答「策略是不是正期望」），本图纵轴是 EV 的 R 倍数（回答「每笔平均赚多少 R」）。图上必须画：① **累计 R 均值主线**（每加一笔交易后重算的累计平均 R，即序贯 EV 点估计）；② **频率派 95% CI 不确定带**（下界、上界 = EV ± 1.96·s/√n，与 review.py「频率派对照」同口径，下界与上界围成不确定带）；③ **EV=0 中性线**（正 / 负期望分界）。主线从 N=1 起画（N=1 时算不出 s、没有 CI，只画一个点），CI 从 N=2 起（s 需 N≥2）。图存 `reviews/YYYY-MM-DD-ev-evolution.png`、嵌入复盘报告，配关键节点表（N / 交易 / 累计均值 / EV 95% CI）+ 解读。**为什么必含**：P(EV>0) 图只看方向与信念强度，看不出幅度——累计均值稳定在 +0.5R 以上 = 不只是正期望、而且有实利 edge；反之 P(EV>0) 高但累计均值只有 +0.1R = 正期望却 edge 很薄。更重要的是 EV 图能暴露**均值被少数大胜主导**的情况：当均值明显高于中位数（分布右偏）时，好看的平均 R 是被个别大胜拉起来的、不代表一致性，需结合中位数与 CI 宽度一起读。两图同源互补：P(EV>0) 看方向与稳健度、EV 看幅度与分布形状，关键节点（探底、转折、CI 转正）应互相对齐印证。画图脚本同 `scripts/bayes_evolution.py`（一次遍历同时产出 P(EV>0) 与 EV 两幅图）。

**每次复盘必含序贯贝叶斯胜率演变图（2026-07-23 用户立，复盘必含项）**：除上方 P(EV>0)、EV 两张演化图外，每次复盘报告还必须再含一张**「贝叶斯胜率随历史所有交易时间顺序逐笔累积」的折线图**。这张图与前两张**同源**——同一组按开仓时间排序的全部已平仓交易、同一横轴（交易序号）；区别只在纵轴：前两图分别是概率 % 与 R 倍数，本图纵轴是胜率 $p$（0~100%）。图上必须画四样东西：① **贝叶斯后验均值主线**（Beta-伯努利共轭，每加一笔交易后更新的胜率后验均值）；② **频率法对照线**（累计 $\text{wins}/N$，即经验胜率）；③ **后验 95% 可信区间不确定带**（下界、上界 = Beta 后验的 2.5% 与 97.5% 分位，下界与上界围成不确定带）；④ **50% 随机中性线**（纯抛硬币分界，作参照）。胜负判定：$R_i>0$ 记为胜（伯努利=1）、$R_i\leq 0$ 记为败（伯努利=0）——与现有 $\mathcal{W}=\{i:P_i>0\}$、$\mathcal{L}=\{i:P_i<0\}$ 口径在无打平样本时完全一致（日内交易打平极罕见、且有手续费使真实打平几乎不存在，统一把 $R_i=0$ 归为非胜）。模型与先验：胜率 $p$ 用 Beta-伯努利共轭（与估 EV 用的 NIG 共轭平行、各自对各自参数共轭），先验默认取**弱信息 Beta(1,1)**（均匀分布 = 拉普拉斯平滑）——不预设胜率偏向（与估 EV 的 NIG 先验 $m_0=0$「不预设 edge」同精神）、后验均值 $(\alpha+\text{wins})/(\alpha+\beta+N)$ 透明可解释（等价于给频率法的分子分母各加 1 个伪计数）、先验强度仅 2 避免主观先验带偏；若想在小样本看到更强收缩，可改用等价样本法设中等强度先验（如 $\text{Beta}(11,9)$、55%、强度 20），但会引入主观胜率假设，本项目默认仍用 Beta(1,1)。每笔增量更新：胜则 $(\alpha,\beta)\to(\alpha+1,\beta)$、败则 $(\alpha,\beta+1)$；后验均值与 95% CI 从 $N=1$ 起即能画（Beta 分布在任一阶段都有均值与方差，这是胜率图比 P(EV>0) 图从 $N=2$ 起、EV 的 CI 从 $N=2$ 起更早出图的优势）。图存 `reviews/YYYY-MM-DD-winrate-evolution.png`、嵌入复盘报告，配关键节点表（N / 交易 / 本笔 R / 胜败 / 频率胜率 / 贝叶斯后验均值 / 95% CI）+ 解读。**为什么必含**：三张演化图各管一维、互补——P(EV>0) 看「策略是不是正期望」的方向与信念强度、EV 看每笔平均赚多少 R 的幅度与分布形状、**胜率图看「胜率这一维随样本怎么稳定下来」**。胜率是仓位的核心输入（凯利最优仓位里胜率 $p$ 线性出现，如标准形式 $f^*=p-q/b$，$p$ 的误差直接传导到仓位），胜率估计不稳 = 仓位估计不稳，故胜率的收敛过程必须单独可见。贝叶斯 vs 频率法对照是本图的独特价值：早期两线分叉大——频率法在小样本剧烈跳动（3 笔全赢就 100%、首笔输了就 0%），贝叶斯向先验收缩（Beta(1,1) 下 3 赢 0 输约 80%、0 赢 3 输约 20%，对照频率法 100% / 0%；若用 Beta(11,9) 则 3 赢 0 输约 61%、收缩更明显），直观量化「胜率估计在第几笔才收敛到可用精度」；后期两线趋同（如 60 赢 40 输时贝叶斯 59.8% ≈ 频率法 60.0%）= 样本已足够、胜率估计可信。这把「贝叶斯比频率法好在哪」从理论落到每一笔的可见证据：小样本防过度自信、大样本回归频率法。不确定带随 $N$ 收窄 = 胜率估计的剩余不确定性，配合样本量规划读「还要多少笔胜率才定得住」。画图脚本同 `scripts/bayes_evolution.py`，在现有一次遍历循环里再加第三段：用同一份 `r_cum`、逐笔判 `R>0` 更新 Beta、调 `scipy.stats.beta.ppf(0.025/0.975, α, β)` 算 CI，一次遍历同时产出 P(EV>0)、EV、胜率、P(g>0)、P(∑₄₀Y≥0)、P(g≥ln1.2/40)、P(∑₄₀Y≥ln1.2) 共七幅图（后四幅见下四段）。

**每次复盘必含序贯 P(g>0) 演化图（2026-07-26 用户立，复盘必含项）**：除上方 P(EV>0)、EV、胜率三张演化图外，每次复盘报告还必须再含一张**「固定比例下注下，每笔对数增长率 $g=\mathbb{E}[\ln(1+fR)]>0$ 的后验概率，随历史交易逐笔累积」的多 f 折线图**。与前三张**同源同横轴**（同一组按开仓时间排序的全部已平仓交易、横轴交易序号），纵轴是 P(g>0)%。**为什么需要 g 而不只是 EV**：累计收益率 $\approx e^{ng}-1$（不是 $(1+f\cdot EV)^n$，后者丢方差惩罚），$g>0$ 才长期复利增长；而 $g=\mathbb{E}[\ln(1+fR)]\approx f\cdot EV-\frac{f^2}{2}\mathbb{E}[R^2]$，**方差惩罚项 $\frac{f^2}{2}\sigma^2$ 让 EV>0 不蕴含 g>0**——故 P(EV>0) 作为「不亏概率」不严谨、P(g>0) 才是。**多 f 折线**：同一组样本、不同风险比例 $f$ 各画一条（默认 $f=0.5\%/2\%/10\%/25\%/50\%$，覆盖保守→凯利 $f^*$→$2f^*$ 临界），展示 $f$ 对「是否有 edge」的影响——小 $f$ 区（$\ln(1+fR)\approx fR$ 线性、信噪比 $\hat g/s_Y$ 与 $f$ 无关）各曲线几乎重合，大 $f$ 区（接近 $2f^*$）方差惩罚显现、P(g>0) 明显下降。计算用频率派 $t$（$P=t\text{-cdf}(\sqrt{N}\hat g/s_Y, N-1)$）+ $\sigma$ 不确定区间（`ppos_empirical` 两端正态）；**不用 NIG(b0=1)**——该先验假设 $\sigma^2\sim1$，对 R（$\sigma^2\sim5$）几乎无影响，但小 $f$ 时 $Y$ 被压缩到 $\sigma^2\sim10^{-4}$、b0=1 先验主导后验严重扭曲结果（实测 $f=0.5\%$ 把 P 从 ~94% 压到 52%）。从 $N=2$ 起画。图存 `reviews/YYYY-MM-DD-pg-evolution.png`、嵌入复盘报告，配终局表（$f$ / $\hat g$ / P(g>0) / $\sigma$ 不确定区间）+ 解读。画图脚本 `scripts/bayes_evolution.py`，调 [review.py](.claude/skills/trade/scripts/review.py) 的 `p_g_pos(R, f)`。

**每次复盘必含序贯 $P(\sum_{i=1}^{40} Y_i\geq 0)$ 演化图（2026-07-26 用户立，复盘必含项）**：除上方四张演化图外，每次复盘报告还必须再含一张**「固定比例 $f$、未来 40 笔对数收益和 $\geq 0$ 的预测概率，随历史交易逐笔累积」的多 f 折线图**（$n=40$ 固定，评估「接下来 40 次交易不亏的概率」）。与 P(g>0) 图同源同横轴，区别：P(g>0) 回答「**长期是否有 edge**」（$N\to\infty$ 不亏），本图回答「**接下来 40 笔不亏**」（有限 $n$ 预测、即便 edge 确认也可能短期亏损）。计算用频率派 $t$ 预测近似：$t\text{-stat}=\sqrt{\frac{nN}{N+n}}\cdot\hat g/s_Y$、df=$N-1$（$n=40$ 固定），$\sigma$ 不确定区间用正态两端；多 $f$ 折线（同 P(g>0) 图的五个 $f$）。从 $N=2$ 起画。**与 P(g>0) 图对照读**：P(g>0) $\geq$ P($\sum_{40}Y\geq0$)（长期概率 $\geq$ 有限笔概率，因 $t$ 系数 $\sqrt{N}>\sqrt{nN/(N+n)}$）；两者差距反映「即便 edge 确认、40 笔内仍可能因波动亏」的短期风险。图存 `reviews/YYYY-MM-DD-psum40-evolution.png`、嵌入复盘报告，配终局表（$f$ / P($\sum_{40}Y\geq0$)）+ 解读。画图脚本 `scripts/bayes_evolution.py`，调 [review.py](.claude/skills/trade/scripts/review.py) 的 `p_sum_y_pos(R, f, 40)`。

**每次复盘必含 P(累计收益率 ≥ 20%) 演化两图（2026-07-26 用户立，复盘必含项）**：除上方 P(g>0)、P(∑₄₀Y≥0)（target=0「不亏」）两图外，再各画一幅 **target=20%** 的——阈值从 0 提到 $\ln(1.2)$：① `pg20` = $P(g\geq\ln1.2/40)$ 演化（g 后验版，40 笔累计≥20% 所需 g）；② `psum40-20pct` = $P(\sum_{40}Y\geq\ln1.2)$ 演化（预测版，未来 40 笔累计≥20%）。多 f 折线（同前五个 f）、从 $N=2$ 起。**意义**：量化「保守比例能不亏但可能达不到收益目标」——实测 N=20 时 f=0.5% 的 P(≥20%)≈46%（ĝ=0.44%/笔、40 笔预期累计 19%，略低于 20% 阈值），f=2% 才达 90%+。这把「保守保不亏 vs 进取达目标」的权衡量化可见，是选 f 的关键判据之一。画图脚本 `scripts/bayes_evolution.py`，调 [review.py](.claude/skills/trade/scripts/review.py) 的 `p_g_target(R,f,n,target)` / `p_sum_y_target(R,f,n,target)`（`target=0` 退化为 `p_g_pos`/`p_sum_y_pos`）。

**每次复盘必含「科学选 f」分析（2026-07-26 用户立，复盘必含项）**：选下注比例 f 不凭直觉，必须用**四步框架**给出可复现的判据，写进每次复盘报告。① **约束优化**——以「不亏」为硬约束（$P(\sum_{40}Y\geq0)\geq95\%$）、最大化「达目标」概率（$P(\sum_{40}Y\geq\ln1.2)$，target=20%），对 f 细网格（如 0.5%~25%、步长 1%~2%）实算两曲线、求约束下 $P(\geq20\%)$ 峰值 → **数学最优 f**（N=20 实测 ≈10%）。② **凯利交叉验证**——数据估 $f^*=p/|R_L|-q/R_W$（⚠️ 小样本 + 移动止损锁利致样本 $|R_L|<1$、$f^*$ 系统性高估，仅作参考、不可全信），确认所选 f 落在保守分数凯利区（如 ≈1/7~1/4 $f^*$）。③ **稳健性收缩（按 edge 状态）**——edge 未确认（$P(g>0)$ 下界<95%、胜率 CI 下界贴 50%、大胜主导）→ 收缩到当前风控上限 $f_{max}$（如 2%）；edge 确认后（$N\geq50$、$P(g>0)$ 下界>95%、胜率 CI 下界脱离 50%）→ 释放到约束优化解。④ **尾部红线**——f 硬上限 = $P(\sum_{40}Y\geq0)$ 跌破 95% 的临界（如 f≤15~20%）。**报告必含三件**：ⓐ f 细网格的两曲线表（$P(\sum_{40}Y\geq0)$、$P(\sum_{40}Y\geq\ln1.2)$ 随 f）；ⓑ 决策表（当前阶段 f / edge 确认后 f / 尾部上限三档）；ⓒ「不亏≠达目标」的核心认知（f 小可保不亏但 $P(\geq20\%)$ 可能很低，如 f=0.5% 时 P(不亏)=96% 但 P(≥20%)=46%——保生存看 $P(g>0)$、达目标看 $P(\geq20\%)$，两个约束独立）。⚠️ **所有 f 基于当次样本**——每次复盘用当下数据重算四步、动态调整 f，不固化（曲线峰值、凯利 $f^*$ 都随样本变）。

**样本定义（T = 一笔交易，2026-07-27 修订与「一笔交易定义」一致）**：**一笔交易 = 一次开仓量 或 一次加仓量**（建仓批次，见「概念区分·一笔交易定义」），一笔交易计为一个 T（一个样本）。一个建仓批次若分多次了结（如先减仓一半 🟠、再止损平剩余 🔴、或移动止损 🟡 触发被动平仓），**多次了结合并为该笔一笔交易**——按加权 exit 价、总盈亏（各次了结盈亏之和）、批次整体 max_loss 算**一个 R-multiple**，不拆成多个样本。⚠️ **不存在「未平仓」的样本**——「持仓不过夜」纪律下，所有建仓批次在当日停止盯盘前（港股 12:00 午休前 / 16:00 收盘前、美股用户喊停或 16:00 收盘前）由 AI 主动了结。**N = 已了结的交易笔数（建仓批次数）**，不是了结事件数。

**统计量定义与推导**（Python 实算各笔 $P_i$ 代入下列公式，不心算）

*Notation.* 已了结样本集 $\mathcal{T}=\{T_1,\ldots,T_N\}$，$N=|\mathcal{T}|$ 为样本总量（= 已了结的交易笔数；一笔交易 = 一个开仓/加仓建仓批次，其多次了结——减仓/平仓/移损——合并为该笔的加权 exit 与总盈亏，计为一个 T）。第 $i$ 笔实际盈亏 $P_i\in\mathbb{R}$（$P_i>0$ 盈利、$P_i<0$ 亏损）。第 $i$ 笔归属批次的实际 max_loss $M_i:=\text{仓位}_i\times\Delta_{\text{stop},i}>0$（各笔按其实际仓位与止损距算、**各笔不同**；选仓位时围绕单笔预算 $B_i=\text{risk\_fraction}\times\text{equity}_i$ 选最近、可略超或略低于 $B_i$、不超 $\text{equity}_i\times f_{\max}$）。

*Definition（净盈亏 / 净 R，net 口径，2026-08-03 用户立）.* 复盘里所有盈亏、赔率、EV、胜率、贝叶斯 $P(\mathrm{EV}>0)$ 一律按**扣双边手续费后的净额**计算（此前为毛口径、未扣费，2026-08-03 改正）：

$$P_i^{\text{net}}:=P_i^{\text{gross}}-\text{fee}_i,\qquad \text{fee}_i=\text{单边费率}_i\times(\text{入场额}_i+\text{平仓额}_i),$$

即开仓、平仓两边各按成交额收一次单边手续费（一买一卖各算一边）。**单边费率按市场**：港股 18bps/边（$0.0018$）、美股 3bps/边（$0.0003$；$1\text{bps}=0.0001$），由 `symbol` 前缀 `HK.` / `US.` 判定。分母 $M_i$（max_loss）**保持毛值不动**——它是开仓前定下的风险预算、归一化标尺，不被费率改动。**下文凡写 $P_i$ 默认指净盈亏 $P_i^{\text{net}}$**；脚本 `scripts/review.py` / `scripts/bayes_evolution.py` 已在算 $R$ 的源头扣双边费、下游全部自动跟随净口径。⚠️ 真实交易另有印花税 / 平台费 / 最低佣金等，此处只按用户给的单边费率做近似扣费；未来要更精细可在 `trades.csv` 加 `fee` 列覆盖。⚠️ **费率对窄止损策略冲击极大**：止损距越小、$M_i$ 越小，$\text{fee}_i/M_i$ 占比越高（极端如止损距 0.4% 的港股单，双边费可吃掉毛盈利的九成）——故窄止损小单在净口径下 edge 极薄，这是改净口径后 EV 明显下降的主因。

*Definition（R-multiple）.* $R_i:=P_i^{\text{net}}/M_i$（**净**盈亏 ÷ 该笔实际 max_loss；选最接近 $B_i$ 的离散仓位定下仓位后 $M_i$ 随之确定）。⚠️ 改净口径后「$R_i\geq -1$」**不再严格成立**：止损触发时实际亏 $M_i+\text{平仓费}$，故净 $R_i$ 可略低于 $-1$——这是真实情况（止损时确实比毛预算多付一笔平仓费），非数据错误。

划分 $\mathcal{W}:=\{i:R_i>0\}$（胜）、$\mathcal{L}:=\{i:R_i\le 0\}$（败，**含平手 $R_i=0$**——与「胜率演化图」$R_i\le 0$ 记败同口径，保 $N=N_W+N_L$、$q=1-p$ 严格成立；日内交易打平极罕见，本项目仅 SOXL 07-08 一笔），$N_W:=|\mathcal{W}|$、$N_L:=|\mathcal{L}|$，$N=N_W+N_L$。

*Definition（胜率 / 败率 / 胜赔率 / 败赔率）.* 胜赔率 $R_W$ / 败赔率 $R_L$ = 胜 / 败笔的平均 R-multiple（败笔含平手 $R_i=0$、故 $|R_L|$ 会被向 0 方向拉低、反映「没赢」；各笔按自身 $M_i$ 归一化后再平均、不要求各笔 $M_i$ 相同）。
$$p:=\frac{N_W}{N},\quad q:=\frac{N_L}{N}=1-p,\quad R_W:=\frac{1}{N_W}\sum_{i\in\mathcal{W}}R_i\;(>0),\quad R_L:=\frac{1}{N_L}\sum_{i\in\mathcal{L}}R_i\;(\in[-1,0))$$

*Proposition（EV 分解—合并恒等）.* 定义期望收益 $\mathrm{EV}:=p\,R_W+q\,R_L$——**只由胜率 $p$、败率 $q$、胜赔率 $R_W$、败赔率 $R_L$ 四个统计量决定、$M$ 不进 EV 公式**（$M$ 仅在更早的 $R_i=P_i/M_i$ 归一化时用、不出现在 EV 的计算里）；它等价于各笔 R-multiple 的均值 $\dfrac{1}{N}\sum_{i=1}^{N}R_i$（合并恒等见下）。

*Proof.*
$$\begin{aligned}
pR_W+qR_L
&=\frac{N_W}{N}\cdot\frac{1}{N_W}\sum_{i\in\mathcal{W}}R_i+\frac{N_L}{N}\cdot\frac{1}{N_L}\sum_{i\in\mathcal{L}}R_i\\
&=\frac{1}{N}\!\left(\sum_{i\in\mathcal{W}}R_i+\sum_{i\in\mathcal{L}}R_i\right)\\
&=\frac{1}{N}\sum_{i=1}^{N}R_i=\mathrm{EV}.\qquad\blacksquare
\end{aligned}$$

*Corollary（预估 EV）.* 开仓前取预估**净**胜赔率 $\hat{R}_W\geq 1.2$（净口径，扣双边费，见 `trading-strategy.md`「赔率三阶段」）、保守取 $R_L=-1$（假设每次亏满 $M_i$、即 $R_i=-1$），则 $\mathrm{EV}_{\text{est}}=p\,\hat{R}_W-q$，即「交易策略纪律」的 $EV=\text{胜率}\times\text{赔率}-\text{败率}$。

*Definition（百分制 / 金额制）.* $\mathrm{EV}\%:=100\,\mathrm{EV}$（百分制 R-multiple）；$\overline{P}:=\dfrac{1}{N}\sum_{i=1}^{N}P_i$（平均每单盈利金额，直接平均各笔绝对盈亏；各笔 $M_i$ 不同时 $\overline{P}\neq M\cdot\mathrm{EV}$，故金额制独立定义、不经统一 $M$）。

*Definition（过程指标 MAE / MFE / 回吐 / 锁利效率，2026-07-21 立）.* 终局盈亏 $R_i$ 是滞后指标（要等平仓、且样本效率低）；持仓过程指标逐笔即可观测、信息量大得多，专门用于样本不足时早期暴露问题。记第 $i$ 笔持仓期间（开仓时刻 → 平仓时刻）按持仓方向的最大不利偏移浮亏、最大有利偏移浮盈，各自除以 $M_i$ 归一化到 R 单位：

$$\mathrm{MAE}_i\in[-1,0],\qquad \mathrm{MFE}_i\in[0,+\infty).$$

（做多：$\mathrm{MAE}_i$ 取期间最低价、$\mathrm{MFE}_i$ 取期间最高价，相对开仓价；做空方向互换。两者均为对应浮亏 / 浮盈峰值金额 $\div M_i$。）

$$\text{回吐}_i:=\max(\mathrm{MFE}_i-R_i,\ 0)\geq 0.$$

> 注：$\mathrm{MFE}_i$ 是持仓期间浮盈峰值、$R_i$ 是平仓兑现值（必然落在峰值之内），故 $\mathrm{MFE}_i\geq R_i$ 恒成立，$\max(\cdot,0)$ 是防御数据异常（跳空 / 滑点 / 采样缺失）的冗余写法、正常情况不改变取值。

*Definition（锁利效率，仅盈利单）.* $\eta_i:=R_i/\mathrm{MFE}_i$（仅当 $\mathrm{MFE}_i>0$ 有意义），含义为实际兑现占峰值浮盈的比例，$\eta_i\to 1$ 锁利越充分。**仅盈利单（$R_i>0$）时 $\eta_i\in(0,1]$ 为有效正值指标；亏损单 $R_i<0$ 时 $\eta_i<0$ 不具「锁利」语义**，故锁利效率只在盈利单子集上统计。

**分盈亏单报告（关键，避免语义混淆）**：盈利单的「回吐」= 锁利回吐（行情给了机会没抓住，改移动止损 / 止盈）；亏损单的「回吐」= 盈亏落差（由盈转亏 / 止损距离，改入场质量 / 止损时机）。两者改进方向不同，混在一起平均会让指标解读变脏。故过程指标**分盈利单子集 $\mathcal{W}$、亏损单子集 $\mathcal{L}$ 各报一组**：

| 子集 | 报告项 |
|---|---|
| 盈利单 $\mathcal{W}$ | $\overline{\mathrm{MAE}}_{\mathcal{W}},\ \overline{\mathrm{MFE}}_{\mathcal{W}},\ \overline{\text{回吐}}_{\mathcal{W}},\ \overline{\eta}_{\mathcal{W}}$ |
| 亏损单 $\mathcal{L}$ | $\overline{\mathrm{MAE}}_{\mathcal{L}},\ \overline{\mathrm{MFE}}_{\mathcal{L}},\ \overline{\text{回吐}}_{\mathcal{L}}$ |

三者合一个完整故事：$\overline{\mathrm{MAE}}$ 看防守（浮亏峰值，越接近 0 越好）、$\overline{\mathrm{MFE}}$ 看进攻（行情给的机会，越大越好）、$\overline{\text{回吐}}$ 看出场效率（没拿住的浮盈，越小越好）、$\overline{\eta}$ 看锁利充分度（盈利单，越接近 1 越好）。

**⚠️ 数据约束**：算 $\mathrm{MAE}/\mathrm{MFE}$ 需要每笔持仓期间的最高 / 最低价，而现有 signals 记录只有开仓价 + 平仓价两个端点、没有期间 high/low。两种落地：（a）复盘时按开 / 平仓时间戳（均精确到秒）回拉富途历史分钟 K，取该时间窗 max(high)/min(low)——历史样本可补算；（b）**推荐**——以后每笔平仓记录原生多写 `mfe_R`/`mae_R` 两个字段（盯盘时本就在采样价格、零额外成本），复盘直接读、不必每次回拉。历史 4 笔用（a）回补。

**复盘时逐项报告**：$N$（样本总量）；$p,\,q$（胜率 / 败率）；$R_W,\,R_L$（胜赔率 / 败赔率）；$\mathrm{EV}=pR_W+qR_L$ 及 $\mathrm{EV}\%$；$\overline{P}$（平均每单盈利金额）；**过程指标分盈亏单各报一组**（$\overline{\mathrm{MAE}},\ \overline{\mathrm{MFE}},\ \overline{\text{回吐}}$，盈利单加报 $\overline{\eta}$）；用户临时指定的其它分析。

**输出**：表格呈现各项指标 + 简短解读（EV 正负、胜率赔率是否支撑正期望、哪些笔拖后腿 / 哪些笔正贡献）。⚠️ 复盘盈亏按信号记录的参考价与 max_loss 实算，**不涉及真实账户资金**（信号模式：AI 不管账户）。

## 样本量规划：要多少笔才可信（2026-07-21 立）

胜率 / EV 等终局统计量是**渐进结论**——大数定律只保证 $N\to\infty$ 时样本均值收敛到期望，**不回答「第几笔收敛到多准」**（大数定律给方向、中心极限定理给刻度）。要回答「多少笔够」，用中心极限定理 + 置信区间 / 功效分析。⚠️ **所有公式的方差都用当前样本估的标准差 $s$ 代入——故样本量需求随真实参数变、且小样本估的 $s$ 本身高方差，这只是「用当前最粗估计做的初步规划」、不是定论。**

三个公式（95% 置信取 $z=1.96$）：

1. **胜率 $p$（比例）**：$\displaystyle n=z^{2}\,p(1-p)/d^{2}$，$d$ 为胜率绝对误差。$p=0.5$ 时方差最大、最保守（实测胜率常接近 0.5，故默认按 0.5 估）。
2. **EV 估计精度（均值 CI 半宽）**：$\displaystyle n=z^{2}\,s^{2}/d^{2}$，$s=\mathrm{std}(R_i)$，$d$ 为 EV 绝对误差（R 单位）。
3. **确认 $\mathrm{EV}>0$（单样本单侧 $t$ 检验功效，$\alpha=0.05$）**：$\displaystyle n=(z_{\alpha}+z_{\beta})^{2}\,s^{2}/\mu^{2}$，$\mu$ 为假设的真实 EV、$1-\beta$ 为把握（80% → $z_\beta=0.84$、90% → $1.28$）。正态近似、小样本偏乐观。

**读法示例（N=4 快照，$s=0.638$，仅示范如何读、不是定论）**：

| 指标 | 误差 / 假设 | 需要样本 |
|---|---|---:|
| 胜率（$p=0.5$） | ±5% | 384 笔 |
| 胜率（$p=0.5$） | ±3% | 1067 笔 |
| EV 估计 | ±0.2R | 39 笔 |
| EV 估计 | ±0.1R | 156 笔 |
| 确认 EV>0（80% 把握） | 真实 EV=0.05R | 1006 笔 |
| 确认 EV>0（80% 把握） | 真实 EV=0.10R | 252 笔 |
| 确认 EV>0（80% 把握） | 真实 EV=0.20R | 63 笔 |

核心规律：**EV 越薄（越接近打平），确认它 $>0$ 需要的样本越多（与 $\mu$ 平方反比）**。若策略真有 0.20R 的厚期望，约 63 笔可 80% 把握确认；若只有 0.05R，要上千笔。⚠️ **鸡生蛋提醒**：上表数字基于 $N=4$ 估的 $s$，真实 $s$ 可能差很多、需求随之大幅变动——这只是初步规划；且当前实测 EV=+0.19 是点估计、其 95% CI 横跨 $[-0.43,+0.82]$ 跨过 0，**现有样本根本不足以判断策略正负**。每次复盘用当下样本重算 $s$ 后重填此表。

## 多层评估框架：样本不足时怎么评估交易水平（2026-07-21 立）

本项目是 AI 主观交易、**不可回测**（LLM 不可 100% 复现、有前视偏差，见「表现验证」节），样本只能靠盘中实战积累、时间成本高。**核心转换：从「等够样本算终局 EV」转向「逐笔榨过程 + 剥离运气」**——胜率 / EV 只衡量「结果」这一个维度且最吃样本量，而决策过程质量、纪律执行、信息利用三个维度都可逐笔即时评估、不需几百笔。类比评估棋手：不必等下满 400 盘看胜率，每一手「当时局面下是不是好棋」可即时复盘评定。四层方法，从「当笔就能用」到「长期攒样本时榨干每笔」：

### 一、即时层（每笔就能评，不等样本量）

1. **决策过程审计（评分卡）**：每笔开仓同时记「决策是否合规」——是否顺势、入场类型是否落在「回踩企稳 / 突破回踩」（而非「赌突破」）、赔率是否达标（门槛见「交易策略纪律」开仓基准与「发信号前自查清单」，不在此写死以免不同步）、止损位是否给足波动、置信度是否匹配；盘后逐笔回评。**决策违规率**（多少笔违反自己立的规矩）是比胜率更早暴露问题的指标，且可归因（纪律问题 vs 方向问题）。现有 4 笔里即有 2 笔决策瑕疵（07-07 美团#2 赌突破、07-15 07709#2 无量企稳做多）。
2. **过程指标 MAE / MFE / 回吐 / 锁利效率**：见上方 Definition——把原本要几百笔才能从 EV 读出的「锁利能力差 / 防守松」，压缩到个位数样本显形。
3. **置信度校准（calibration）**：看实际胜率是否随开仓置信度（🟢 / 🟡 / 🔴）递增。🟢 高置信实际胜率与 🟡 无差别 = AI 不知道自己何时真懂、何时在猜（元认知没校准）。有标了置信度的样本即可开始看趋势。

### 二、累积层（边攒边更新，专门为「样本贵」设计）

4. **贝叶斯更新（完整贝叶斯 NIG 共轭，σ 也估；2026-07-21 修订：弃经验贝叶斯）**：不必等凑齐固定 N 再判——给 EV 一个先验、每平一笔用 $R_i$ 更新后验，后验逐步变窄、动态读「证据更偏向正 / 负期望」。**用完整贝叶斯（正态-逆伽马 NIG 共轭，$\mu$ 与 $\sigma^2$ 联合估计），不用经验贝叶斯（$\sigma$ 固定为样本 $s$）**——后者小样本下系统性偏乐观（忽略 $\sigma$ 自身的不确定性；本项目 N=4：经验贝叶斯 $P(\mathrm{EV}>0)=71.6\%$ vs 完整贝叶斯 $67.0\%$，差 4.5pp）。

   - **模型与先验**：$R_i\sim N(\mu,\sigma^2)$，要估 $\mu=$ EV。NIG 先验 $(m_0,k_0,a_0,b_0)$ 取弱信息默认 $m_0=0$（不预设 edge）、$k_0=1,\ a_0=1,\ b_0=1$。
   - **后验参数**（观测 $R_1,\dots,R_n$、样本均值 $\bar R$、离差平方和 $S=\sum(R_i-\bar R)^2$）：

     $$m_n=\frac{k_0 m_0+n\bar R}{k_0+n},\quad k_n=k_0+n,\quad a_n=a_0+\tfrac n2,\quad b_n=b_0+\tfrac12 S+\frac{k_0 n(\bar R-m_0)^2}{2(k_0+n)}$$

   - **$\mu$ 的边缘后验为 t 分布**：$\mu\,|\,\text{data}\sim t_{2a_n}\!\left(m_n,\ \sqrt{b_n/(a_n k_n)}\right)$（自由度 $2a_n$、位置 $m_n$、尺度 $\sqrt{b_n/(a_n k_n)}$）。
   - **核心输出 $P(\mathrm{EV}>0)$**：$\displaystyle P(\mathrm{EV}>0)=1-T_{2a_n}\!\left(\frac{-m_n}{\sqrt{b_n/(a_n k_n)}}\right)$（$T_\nu$ 为自由度 $\nu$ 的 t 分布 CDF）。
   - **⚠️ 统一带区间输出（小样本、大样本一律，2026-07-21 立）**：单点 $P(\mathrm{EV}>0)$ 依赖 $\sigma$ 估计、而 $\sigma$ 小样本下极不确定（N=4 时 $\sigma$ 的 95% CI 跨 6.6 倍），**禁止只报单点**。必须配敏感性范围，格式一律：**「$P(\mathrm{EV}>0)=X\%$（$\sigma$ 不确定下 $Y\%\sim Z\%$）」**。敏感性范围算法：取 $\sigma$ 的 95% CI（卡方）$\big[\sqrt{(n-1)s^2/\chi^2_{0.975,n-1}},\ \sqrt{(n-1)s^2/\chi^2_{0.025,n-1}}\big]$，在两端各算一次后验 $P(\mathrm{EV}>0)$（近似用固定 $\sigma$ 的正态后验即可），取其范围。示例（本项目 N=4）：「$P(\mathrm{EV}>0)=67\%$（$\sigma$ 不确定下 $54\%\sim 85\%$）」。
   - **判读纪律**：小样本（敏感性跨度 >5pp 或点值近 50%）**只取方向（略偏正 / 负）、不取数值、不作加仓 / 改策略决策**；大样本（跨度 ≤5pp 且点值远离 50%）点值才有参考价值、区间整体 >95% = 确认正期望。跨度随 $N$ 按 $1/\sqrt n$ 收窄：N=4~10 不可确认、N=20~30 边界、N≈50+ 才有确认价值（与「样本量规划」一致）。**关键认知：贝叶斯不绕过样本量约束**——与频率派受同样信息量限制，小样本下 $P(\mathrm{EV}>0)$ 的「精确」是表象、底层不确定性与频率派宽 CI 等量。
   - **序贯检验 SPRT（同源可选，复盘通常不必，2026-07-21 降级）**：Wald 序贯概率比检验——边收数据边检验、$\Lambda_n$ 跨边界即判（接受 H₁ 有 edge / 接受 H₀ 无 edge / 继续）。**关键：$\Lambda_n$ 本质就是对数贝叶斯因子，与上方贝叶斯 P(EV>0) 同源、信息重叠**——「SPRT 接受 H₁」≈「贝叶斯 P(EV>0) > 阈值」，未给出贝叶斯后验之外的信息。SPRT 仅有的独有价值是**明确的停止规则 + 频率派错误率保证（α、β）**，只在需要「自动判决程序 / 策略上线 gate（攒够证据才放量）」时才用得上；纯复盘评估用贝叶斯 P(EV>0)（带敏感性区间）即可，**SPRT 不必另算**。本项目样本被动慢积累、SPRT「早停省样本」红利有限，故复盘脚本 `review.py` 不实现 SPRT。
5. **按情境分类合并**：总样本少，但按方向 / 入场类型 / 标的类型 / 市场 / 置信度分组后，同类样本合并更早收敛。「赌突破类反复亏」这类模式，十来笔就能暴露——要的不是 400 笔混合样本，而是「哪类情境下反复出错」。

### 三、对照层（剥离运气，回答「盈亏里多少是 AI 的功劳」）

6. **反事实基准**：对每个开仓信号事后算三个对照——随机开仓同标的（随机基准）、从开仓点到平仓点标的本身涨跌（买入持有基准）、反向做（反向基准）。连续多笔「反向更赚」= 方向判断系统性反了。**基准跑赢占比**是比胜率更干净的「水平」度量。
7. **量化策略基准**：见「表现验证」节——写一套可回测的纯 K 线量化策略（5 日顺势 + 放量突破回踩等），回测标定可信度。它同时也是评估 AI 水平的标尺：AI 信号 vs 量化信号的一致率、分歧时谁对，直接量化 AI 相对「可形式化策略」的增量价值（K 线数据富途有 5.5 年分钟级、回测零成本）。

### 四、覆盖层（保证结论能泛化）

8. **刻意覆盖多市场环境**：小样本最大风险是偏在单一环境（如 4 笔全是大跌反弹日做多）。主动确保样本覆盖趋势 / 震荡 / 大涨 / 暴跌 / 数据日等多种环境——环境多样性比样本数本身更影响结论可靠度。

**诚实边界**：以上方法的作用是「样本不足时榨干每笔信息、尽早暴露问题、避免自欺」，**不取消对真实样本的需要**——「策略长期正期望」这个终极判断没有捷径、终归靠积累。区别只是：只看胜率 / EV 要 60–250 笔才出信号、期间两眼一抹黑；加上过程审计 + MAE/MFE + 校准 + 反事实基准，**第 5 笔就开始出可归因的信号**。
