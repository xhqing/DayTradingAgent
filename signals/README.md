# 信号记录（用户下单基准 + 复盘用，港美分文件）

本目录持久化每个交易日发出的信号。**信号文件是用户下单的基准**——用户实际参照下单的是这里的内容，不是对话里的表格（对话流会把信号推走、易丢失，文件才是稳定可回查的基准）；同时供事后复盘统计（胜率 / 赔率 / EV 收益）。

**信号时序（2026-08-02 立，三步连贯）**：决定发信号后，**第一个动作是把信号内容写入本目录的当天文件**（`log_signal.sh`，标题行后自动带发信号时间戳），**第二个动作是响铃**（`ring.sh` + 记录响铃时刻到 `ring-log.csv`，时间精确到秒），**第三个动作是 snapshot 取响铃时刻价**、以一行注释 append 到该条信号末尾。三步之间不插入任何其它动作——取价紧跟响铃、零间隔，取到的实测价才近似用户实际成交价。完整时序与调用方式见 `../references/signal-mode.md`「信号时序总则」。

## 文件命名（2026-07-15 港美分开）

- 港股信号：`YYYY-MM-DD-HKT-signals.md`
- 美股信号：`YYYY-MM-DD-ET-signals.md`

文件名带 HKT / ET 时区标识，港股、美股信号分别记录，便于按市场分别复盘。

## 规则

- **港美分开、每天每市场一个文件**（如港股 `2026-08-12-HKT-signals.md`、美股 `2026-08-12-ET-signals.md`）。
- **先写文件、再响铃、最后取响铃时刻价**：决定发信号后第一个动作 = `log_signal.sh` 把信号内容 append 到对应市场文件（信号内容经 stdin 传入），第二个动作 = `ring.sh` 响铃 + 写 `ring-log.csv`，第三个动作 = snapshot 取响铃时刻价 append 到该条信号末尾（时序见 `../references/signal-mode.md`「信号时序总则」）。
- **每条信号含**：`##` 标题（如 `## 🟢🟢🟢 开仓 · <标的代码> <中文名> · 做多 🟢🟢🟢`，标题行后自动带发信号时间 HH:MM:SS）+ 字段表格 + 结果注释（响铃后成交价、平仓后的盈亏与实际落地赔率等）。**条目分隔用 `##` 二级标题、不强制 `═══` 框线**（2026-08-04 起实际格式已统一为 `##` 标题，旧框线格式不再要求；表格内不放装饰 emoji，开仓的参考价与止损价加粗，详见 `../references/signal-mode.md`「三类信号格式」）。发信号时间精确到秒。
- **记录字段**：发信号时间、标的（代码 + 中文名）、方向、量、参考价、成交价（响铃时刻价，末尾注释）、止损、止盈、单笔预算 B + 预估 max_loss（响铃后按实测价修正为实际 max_loss）、置信度、依据、风险提示。**B = risk_fraction × 当前 equity 允许写、equity 本体数值不写**（2026-08-20 改：equity-log 累加链已与用户实盘账户对齐，信号文件里的净值数字实际就是实盘净值，属敏感财务信息——表格写「HK$2,319（= 2% × 当前 equity，数值见本机 equity-log）」这类口径，每笔了结末尾 append 盈亏与 B、不 append 总资产数字；equity-log.csv 本身自 2026-08-20 起被 .gitignore 忽略、只留本机）。**账户号 / API 凭证等敏感信息不写**（2026-08-17 起账户号一律打码口径；2026-08-20 起实盘净值同禁，见项目 CLAUDE.md「实盘净值禁止写入被跟踪文件」节）。
