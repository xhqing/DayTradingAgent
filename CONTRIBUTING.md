# Contributing

Thanks for considering a contribution. This document covers the two things you
most likely want to know before you start: what happens to the copyright in what
you send, and under what licence the project uses it.

## You keep your copyright

**Copyright in your contribution stays with you.** Opening a pull request does
not transfer ownership to this project or to its maintainer. A transfer of
copyright would need a written agreement, and a pull request is not one.

The project's copyright notice reads "xhqing and contributors" because
contributors are acknowledged as rights holders in their own right — not
because their rights were signed over.

## The licence you grant

By submitting a pull request, you agree that your contribution is licensed to
this project under the project's own licence:

- **Software projects:** the **MIT License**
- **Non-software projects** (prose, articles, tutorials): the **Creative
  Commons Attribution 4.0 International License (CC BY 4.0)**

That is a licence, not an assignment. You keep the copyright; the project gains
permission to use, modify and redistribute your work under that licence.

If you are not comfortable with this arrangement, open an issue first and we can
work something else out before you write any code.

## Before you open a pull request

- For anything beyond a typo or a one-line fix, **open an issue first**.
  Describe what you plan to change and why. Agreeing on the approach up front is
  cheaper than reworking a finished patch.
- Keep one pull request to one concern. Mixed changes are hard to review.
- Run the project's checks locally if it has any.

## Signed-off-by (recommended)

Add a `Signed-off-by` line to your commit message, certifying that you wrote the
contribution or otherwise have the right to submit it:

```
Signed-off-by: Your Name <you@example.com>
```

This is the Developer Certificate of Origin (DCO). It protects the project from
code that came from somewhere it should not have — and it protects you, by
putting your authorship on the record.
